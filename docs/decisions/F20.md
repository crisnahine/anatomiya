# F20

Section: F. Safety

## Decision

The sites a branch introduced are decided in one leaf, `introduced.mjs`, that reaches no git, no child and no disk, and the check is its only importer

## Why

The identity rule, node type plus normalised slice and never the line, was pinned by comments in four other test files, one citing `check.mjs:437` for a line that had moved into `resolveBase`, because the block had no interface of its own: the only way to run it was a repository committed twice.
Moving it gives the rule a namesake test that asserts two golden digests, the one-polarity rule and both modes from one parsed program, and the check's output is byte for byte what it was on a fixture holding a rename, a line shift and an edit inside an existing site
