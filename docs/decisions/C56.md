# C56

Section: C. The counted-claim model

## Decision

A file's class is its directory plus its suffix, from the first dot past any segment starting with a digit, with Ruby's `_spec.rb` and `_test.rb`, Go's `_test.go` and Python's `_test.py` kept whole, and the same suffix one directory up. A suffix of anything but ASCII letters, digits, `.`, `_` and `-` is no class, and a test's class is neither side of a claim

## Why

The first-dot rule split forem's vendored gems into `*.1.0.gem` and `*.2.0.gem`; with this rule forem's `vendor/cache/*.gem` is one class.
Tests are counted file by file by the namesake count and C7, and as a class "adds a spec here" is met by any spec: on rubocop 3 of 8 claims restated the cop claims from the spec side.
A suffix holding prose put repository text into the notice and the area file, so a kind that is not an extension's shape is no class, and a reader ignores a record entry whose producer or companion this rule could not have built.
Unicode letters are left out: no corpus kind is non-ASCII, and they let confusables through.
A Go `x_test.go` once took the plain `.go` class, so it sat on the producer side of a claim over the source beside it: a branch adding only `pkg/h/y_test.go` owed `pkg/h/routes.go`, and in the walk a change that only adds tests was a candidate that did not conform.
Measured on a synthetic history: 40 changes each adding `pkg/h/xN.go` and editing `routes.go` state the claim at 40 of 40, and 5 newer changes adding only a test take it to 40 of 45, 0.889, under the bar; kept whole, the test's class is the walk's test side and is dropped on both sides.

## Status

**done** `cochange.mjs` (`suffixOf`, `classesOf`, `classParts`, `statedClaims`), `cochange-walk.mjs`, pinned by `test/cochange.test.mjs` and `test/cochange-walk.test.mjs`.
A file one directory below the root has no parent class, since `*/*.rb` would span every top-level directory.
Given up: a real class named like `x.2fa.js` merges with `*.js`, and a non-ASCII extension is no class.
A test named by a prefix or a hyphen (`test_x.py`, `login-test.js`) still takes its language's plain suffix.
