# C56

Section: C. The counted-claim model

## Decision

A file's class is its directory plus its suffix, from the first dot past any segment starting with a digit, with Ruby's `_spec.rb` and `_test.rb` kept whole, and the same suffix one directory up. A suffix of anything but ASCII letters, digits, `.`, `_` and `-` is no class, and a test's class is neither side of a claim

## Why

The first-dot rule split forem's vendored gems into `*.1.0.gem` and `*.2.0.gem`; with this rule forem's `vendor/cache/*.gem` is one class.
Tests are counted file by file by the namesake count and C7, and as a class "adds a spec here" is met by any spec: on rubocop 3 of 8 claims restated the cop claims from the spec side.
A suffix holding prose put repository text into the notice and the area file, so a kind that is not an extension's shape is no class, and a reader ignores a record entry whose producer or companion this rule could not have built.
Unicode letters are left out: no corpus kind is non-ASCII, and they let confusables through
