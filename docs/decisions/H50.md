# H50

Section: H. Layout

## Decision

A namesake test in those seven is matched inside the family, with the family's own test spelling stripped and its own tree words read out of both sides of a mirror. Where the family's layout pairs a project with its tests, a test covers the one source file of its stem there, at any depth

## Why

The tree words: a Java or Kotlin path is its package, which is what follows the last `java` or `kotlin` directory, and a Gradle source set drops out where there is none; the `.Tests` or `.Test` on a .NET project; a `Test` or `Tests` directory for PHP.
The pairings: a .NET `X.Tests` with `X`, a Maven or Gradle `src/test` or `<set>Test` source set with what sits beside it, a PHP `tests` with the `src` or `app` beside it; two files of one stem are credited with nothing by a pairing.
A PHP test whose name is its directory's name, alone or with a class after it (`tests/Cookie/CookieTest.php`, `tests/Session/SessionStoreTest.php`), covers by that pairing only a source under a directory of that name, where some source directory of the paired tree carries that name.
A Python package directly under `src` is read as the top of the tree, a Python `tests` directory beside a package mirrors that package, and a Python test below the top of its tree answers only the path it mirrors.
A Python package's `__init__.py` answers as the module its directory is.
A test its build pairs with one source answers no other.
With no stem rule the map reads `0 of 113 .cs files` on serilog, `0 of 152 .kt` on okhttp and `0 of 19` over fastlane's `.java` files.
Measured on how each repository's tests name what they cover: Go beside the source (353 of 578 tests), Java across `src/main` and `src/test` (240 pairs in commons-lang and gson), C# across `X` and `X.Tests` (116 pairs), composer across `src/Composer` and `tests/Composer/Test` (174), which the seven shared tree words do not reach because `main`, `Serilog.Tests` and `Test` stay in the path.
Dropping `main` alone leaves okhttp at 25 of 152, since it names a source set `commonJvmAndroid`, and junit5 at 133 of 583 across its roots, since it tests a module from the module beside it; comparing the package reads 50 and 150 (both taken while junit5's `documentation` root counted the 39 files under its `src/test`; with those in no count its roots sum to 148 of 544), and commons-lang 210 of 246 either way.
