# B82

Section: B. Engine

## Decision

The Ruby child sends, with each method, class and module node, the comments that end on the line right above it, each alone on its line and unbroken by a blank line (`doc`), and a method's parameters as written (`sig`). The comments are read once per file into a table by the line each ends on

## Why

The code index (H60) shows each definition's parameters and doc sentence, and the JavaScript side of the bridge never holds a Ruby file's text: the child reads the file itself, so nothing repository-derived reaches a command line (B5).
prism's own `attach_comments!` weighs every comment against every node: a valid 286 KB file of 9,000 documented methods went silent past the child's 30-second clock, where the parse alone takes 0.3 seconds, and Homebrew's `formula.rb` attached 50 times slower than it parsed.
It also attaches a license header to the first class below it across blank lines, and the comment above `private def` to the call rather than the method.
A table by line answers all three.
