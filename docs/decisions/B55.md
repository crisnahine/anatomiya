# B55

Section: B. Engine

## Decision

A component's template and style are not read, and the overview says so in one "Not covered" line wherever the corpus holds a component

## Why

A count taken over a directory of components reads as a count over the components, and it is a count over their scripts.
Reading the markup would take each framework's own parser (B52), and what the markup decides is exactly what the excluded rows could not see (B54).
So the map says it, in the file that loads on every turn: `of 17 .vue and .svelte files only the script block is read; the template is not`, naming only the extensions present, the more numerous first, and `file` at a count of one.
The count is every component file in the corpus, one the parser rejected and one with no script included, so the line says which part of such a file is read and does not say a file was read.
It is taken off the corpus, so it does not move with machine load (A5), and it is absent on a repository with no component, so no existing map changes
