# B30

Section: B. Engine

## Decision

A bare RSpec-shaped or declarative-macro call must carry a description argument, not just a block

## Why

`context`, `describe`, `it`, `test` and `test_name` all take a description as their first argument in real use, and the block-plus-no-receiver check alone could not tell a case apart from a FactoryBot attribute: `context { "tags" }` sets a column literally named `context` and takes no argument at all.
Measured on empire-flippers/api: 1 of 734 files under `spec/` misfires this way, inflating the RSpec count by one and putting "1 test file" on `spec/factories`; consul has the same shape once.
The requirement applies to the whole `RUBY_TEST_CALLS` set alike, since none of them is ever called bare in real use either
