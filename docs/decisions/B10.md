# B10

Section: B. Engine

## Decision

**Dimensions run in the worker; only counts cross IPC.** The tree comes back only for the check, which needs line numbers, and only for the files a diff touched

## Why

Measured: the walks are 85% of the scan's CPU (1.57ms/file against 0.27ms to parse) and running them in the parent left that 85% on one core, so pool throughput stopped improving past 4 workers on 11 cores.
The reply for an 18 KB file went 278,261 bytes to 649
