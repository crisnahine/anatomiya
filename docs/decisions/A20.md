# A20

Section: A. Delivery

## Decision

The check answers with a record: a schema, coded caveats and one encoder pass. Text, `json` and `github` are three writers over that one record, at the CLI edge

## Why

The report was prose, so anything but a human told "the diff could not be read" apart from "one file was read from the working tree" by matching wording nobody promised to keep, and the acceptance harness read the numbers by regex off stdout.
Twenty-three sites answered with a sentence and no code
