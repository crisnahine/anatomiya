# E16

Section: E. Baseline and drift

## Decision

The co-change walk's tip is the pin where it loads and is reachable, else HEAD's fork point with the first base ref that resolves, else HEAD, and the record names which as `from`. The check grades a co-change finding MUST-FIX only off a pinned tip

## Why

A branch must not make its own claim.
Off the pin, the agent's own merged work can raise a count the check then grades it by (the E4 argument); off HEAD with no base ref, the branch itself is in the window.
Harness, 9 claim repositories pinned: MUST-FIX on the two probed claims that are perfect and printed (consul 100 of 100, canvas-lms 35 of 35), FIX on the others by their own rung; the harness probes each repository's first stated claim
