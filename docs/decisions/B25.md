# B25

Section: B. Engine

## Decision

A type-only import entry never decides the test runner, and still counts toward what a file's `imports` list says it references

## Why

oxc marks each specifier `isType`, true for `import type { X }` and for a per-specifier `type` modifier, and neither ever reaches the runtime, so neither can be what runs a file.
Measured on next.js: 58 files under `test/` import `@playwright/test` for types alone, so most of "79 playwright" were Jest specs borrowing types.
Kept on the `imports` list itself rather than dropped: a file that types against a library still names something it references, which is the question that list answers, and the roster's "most files here import" line reads it for exactly that, a different question from which module runs the file
