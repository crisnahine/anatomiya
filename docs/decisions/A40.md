# A40

Section: A. Delivery

## Decision

No plugin sits at the repository root. The root is the marketplace and the development tooling; each plugin is a directory under `plugins/`, with its own manifest, its own package and its own release

## Why

A marketplace entry whose `source` is `"./"` is copied whole into the plugin cache, which was read against primary sources rather than inferred.
Measured on this machine, `~/.claude/plugins/cache/crisnahine/anatomiya/0.2.13/` held `test/`, `docs/`, `node_modules/`, a 246 KB `DECISIONS.md`, a 124 KB `CHANGELOG.md` and the whole suite, which every installer paid for.
`package.json` `files` does not govern that copy; only the layout does.
Anthropic's own marketplace is the one first-party signal there is: of its 286 entries, 53 name a relative source, 38 under `./plugins/` and 15 under `./external_plugins/`, and none is `"./"`.
What the move bought beyond the copy is that the gates stopped needing a special case: `validate.mjs` had three `pluginRoot === resolve(root)` tests and a root-only `required: true`, and every one of them is gone, so every listed plugin is read by one path and the plugin whose hooks are required is named on the marketplace instead of inferred from a position; `shipped.mjs` now answers for every plugin the marketplace lists rather than for the one it happened to sit in.
The cost was measured before it was paid and it was the measurement in A38: 62 tracked files moved, file after file referenced them, and the reference is now one module, `scripts/plugins.mjs`, which both the suite and the gates read.
One thing was given up: the plugin is a workspace member, so npm keeps the single lockfile at the marketplace root and the plugin directory has none, which is what Claude Code's automatic `npm ci` looks for.
That install was never the documented path, `/anatomiya:setup` is, and the README said so before this change
