# A120

Section: A. Delivery

## Decision

The overview's Not covered section names what no row opens or reads: a clause counting the configuration, data and prose files by extension beside the languages it does not read, the template and component formats among those languages, and a clause, the same on every repository, saying which strings a row reads: an import path, JSX text, a doc comment, a quoted object key, a few Rails arguments and a declared URL path. Each clause shares a line the section already prints, so the overview keeps its forty lines

## Why

A map silent about a file reads as a map that checked it.
Across the 35-repository corpus 91,369 of 268,541 tracked files that pass the deny list are never parsed, 0.340 of them, and the old line named only languages: discourse's 2,944 `.gjs` components, 461 `.coffee` files and every `.hbs` template said nothing at all.
The string line is static because it describes the tool rather than the repository, and #238 is the case it would have told a reader: no row read the route table's strings.
One line in the overview costs every turn once, where the same line in each area file would cost every area file.
The clauses share lines because the overview holds forty lines with every optional line on: as lines of their own they took it to 41, which the bound sweep in `test/render.test.mjs` caught once its corpus held a data file.
The same sweep, given a component's script line and a generated file as well, showed a truncated scan's overview dropping "What lives where" whole, and main's renderer did too: the unread kinds (another language, data and prose, a component's template, a generated file) now share one line, and the files the parse could not read share another
