# C7

Section: C. The counted-claim model

## Decision

A file-to-file obligation is a dimension whose site is the file, counted over the corpus rather than over a tree. Every such row carries `companionsElsewhere`: producers whose companion is missing where the predicate looks, which C9 now learns rather than declares and whose namesake exists elsewhere. A repository is asked the question only for a companion suffix it actually uses

## Why

Every other dimension asks a question inside one file, and a review comment is as often about a missing companion as about syntax.
Two things a first cut got wrong and the measurement caught.
A ratio of zero has two meanings, so the audit count is what separates them: on alphagov/whitehall the `app/models` area scores 0 of 160 and 117 of those models have a test one directory deeper, which without the count reads as a repository that does not test its models.
And producers exist whatever a repository tests with, so counting both the RSpec and the minitest row put a line that can only read zero into every Rails map
