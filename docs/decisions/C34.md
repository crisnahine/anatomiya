# C34

Section: C. The counted-claim model

## Decision

An option is the value Rails reads for it: the key it looks up, the truthiness it tests, and only where the source decides that value

## Why

C33 closed the key half and three more sat behind it, each found by executing the rows against the corpus rather than reading them.
Rails looks an option up by symbol, so `"null" => false` is a hash entry and not the `null:` option, and reading it as one credits a column that declares nothing; a string key is skipped now rather than voiding the list, since it is readable and what it reads as is not the option.
Ruby's truthiness is what Rails tests, not the literal `true`: `polymorphic: { limit: 255 }` is the type column's own options and `polymorphic: %i[account course]` is the list of types, and 26 of the corpus's 129 polymorphic references are written one of those two ways, all in canvas-lms, every one of them charged for the foreign key ActiveRecord refuses.
And a value the source does not decide decides nothing: `null: nullable` may be declaring `null: false`, and `foreign_key: fk_options` may be declaring nothing, which whitehall writes once and this credited.
The exclusion is lifted for the list form alone, where the options declare the key beside it: canvas patches `TableDefinition#references` to expand `polymorphic: %i[account course]` into one real reference per type with `foreign_key:` passed to each, and its own guard is `unless polymorphic.is_a?(Array)`, so a hash and a bare `true` fall through to stock ActiveRecord and raise.
10 of the 26 are the list form with a key, and excluding them denies a fact that repository's source demonstrates, while lifting on any truthy value would credit a migration that cannot run.
The same reading settles `foreign_key:`, which Rails tests for truthiness: `nil` adds no key and read as one it credited a column that has none.
`null:` is the one option still compared against the literal `false`, because `add_column_options!` compares it that way.
Measured over 35 repositories: reference sites 1,655 to 1,638, of which 16 are the polymorphic exclusion and 1 the unread `foreign_key:`; conforming 1,186 to 1,185; the column and `create_table` rows do not move.
Keys are matched within one direction as well, since a column added only on the way down does not exist going forward and neither does a key, which C32 already says of the key alone: a rollback reference is still a site, judged against the rollback's own keys, and 8 of the corpus's 1,758 reference calls are written in one, none of whose verdicts moves
