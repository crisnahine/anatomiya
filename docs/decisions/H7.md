# H7

Section: H. Layout

## Decision

Every tracked file counts in the roster, source or not, except the map's own files; a file in no language this tool parses is never a test file

## Why

A directory holding 40 `.md` files is a fact about where things live, so the roster's corpus is the whole `git ls-files` pass under the same deny list rather than the source extensions, and a non-source file is named by its extension and nothing else.
The test side runs the other way, and it was measured: twenty screenshots under `cypress/` are not twenty specs, and counting them made the denominator this whole section exists to be read 24 over 4

## Status

**done** `layout-scan.mjs` (`roster`), `test-shape.mjs` (`isTestFile`), `corpus.mjs` (`ownOutput`), pinned by `test/corpus.test.mjs` and `test/scan.test.mjs`.
Left out: every file under `.claude/anatomiya/` that is not source, and in `.claude/rules`, `.cursor/rules` and `.github/instructions` a file named as a scan names one, the overview or `anatomiya-area-` and eight hex digits with that directory's extension.
By name alone, with no file opened and whether or not that target is on, so turning one off does not move the roster.
Where git reports that the volume folds case (`core.ignorecase`, the question `committedTargets` asks), each of those directories is matched in any case, and `collect` asks git that only when a tracked path is a map name under one of those directories in another letter case, so a repository with no such path starts no process for it.
The directories are matched that way because the writer follows the directory the volume answers with: with `.Cursor/Rules` and `.GitHub/Instructions` committed and the directories compared as spelled, the scan after the commit printed `layout: 4 roots` where the scan before it printed 2, and the overview gained `- .Cursor/Rules: 4 .mdc`.
The file's name is held to its own spelling, since no scan writes another.
Where `.claude/rules` is a link, the directory asked is the one git tracks the map under (`trackedRulesDir`, F2).
Counted, a committed map moves the roster it is part of, which A5 forbids: on a copy of Homebrew/brew with the 58 files of its map committed, the second scan printed a new line `- .claude/rules: 58 .md` and dropped `Library/Homebrew/cask/dsl` from the Areas list to pay for it, and with the rule the two overviews are identical.
None of the 35 corpus repositories tracks a file the rule leaves out, so none of their maps moved.
What this gives up: a hand-written file under one of those exact names is left out of the count too; a repository that commits its map, its pin or `refresh.json` prints a different roster once; and a map directory spelled in another case is still counted where git does not report the fold
