# A13

Section: A. Delivery

## Decision

A language whose parser never answered for a single file is decided on its own: every area holding a file of it is held, and only a run that read no file of any language writes nothing and removes nothing

## Why

Measured: `env -i PATH=/usr/bin:/bin` on a 200-file Rails repository charged every file as a crash, dropped every area, and deleted three correct area files in the same run that reported it could not read them.
Suppressing only the removals leaves the overview claiming zero areas beside area files that still load, so `facts.json` is suppressed with the rest.
The condition is a crash on every file, not an absence of readable ones: a syntax error means the parser answered
