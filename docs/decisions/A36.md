# A36

Section: A. Delivery

## Decision

One module decides whether a script is the file node was told to run, resolving both sides before comparing, and a test refuses the spelling that compares a resolved URL against a path as it was typed

## Why

`import.meta.url` is always resolved and `process.argv[1]` is whatever the caller spelled, so an equality between them answers no for every invocation whose path holds a symlink, and the guarded script runs nothing and exits 0.
The correct spelling was found twice, once for CI's manifest gate and once for a plugin's hooks, and left standing in seven scripts: `scripts/validate.mjs` carries a comment explaining it and `scripts/check-docs.mjs`, the other gate in the same job, does not.
Reproduced by mutating one doc claim in a copy: run directly it printed the error and exited 1, and the same file reached through an absolute symlinked path printed nothing and exited 0, which for a gate is worse than not running.
CI itself cannot trip it, because both its invocations are relative and `process.cwd()` answers the physical path, and the vector is still not hypothetical: `os.tmpdir()` on macOS is a symlink, which is how this repository's own `check-docs` fixture reached it without trying and why that fixture already calls `realpathSync`, and a worktree of this repository sits under `/private/tmp` today.
`seed-defaults.mjs` is the one where the silence would not have been the whole cost: its `main` holds no `process.exit`, so an import that was not guarded overwrites `plugins/anatomiya/lib/model-defaults.json` rather than ending the test run.
It lives under `scripts/` and not `lib/`, because nothing the plugin ships needs one, `plugins/anatomiya/bin/anatomiya.mjs` runs at module scope on purpose, and the shipped set is checked now

## Status

**done** `scripts/entry.mjs` (`invokedAs`) and the thirteen scripts that call it, eight converted with it, three written against it and two that arrived later (`scripts/plugin-lock.mjs` with B35, `scripts/ab.mjs` with its guarded `main`), pinned by `test/entry.test.mjs`, which spawns a gate through a symlink against the same gate spelled directly, drives the argv-less case through `node -e`, deletes a running script's own file to reach the unresolvable path, runs both copies as files of their own so a guard that answered no for itself is caught where symlinks are unavailable, and walks six named source directories for any file that reads `process.argv[1]` at all.
That last rule is about where the value may be read rather than which comparison is written, because the comparisons are not a list.
What a spelling cannot do is separate the two: node absolutises and normalises `argv[1]` before a script sees it, so `.`, `..`, `//` and a relative path all collapse and only a symlink survives, which is why the discriminating case carries `needsSymlinks` and a Windows checkout without the privilege runs the weaker one.
A plugin that needs the same answer keeps its own copy, since a plugin may not run a file outside its own root, and the same test holds the two to one rule
