# H20

Section: H. Layout

## Decision

An area's `kinds:` line names a test group's runner the way a root line does, per group, rather than summing every group into one bare count labelled `test file`

## Why

The two lines already read the same `tests` field `testGroups` built, so summing it on one and naming it on the other stated one fact two ways. plots2's `test/unit/helpers` stated `11 test files` two lines above stating that all 11 inherit `ActionView::TestCase`, never once saying minitest, while the repository-wide overview two sections up correctly said `75 minitest specs` over the same files.
No area file in that repository named a runner for any of its 8 test-holding directories.
The per-group clause is shared with the root line's own rendering rather than duplicated, so the two spellings cannot drift again
