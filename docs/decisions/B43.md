# B43

Section: B. Engine

## Decision

The parser script carries a tree across the stream with no JSON nesting cap; stack exhaustion stays the rescue for a pathological file

## Why

Measured: a 98-branch `elsif` chain, a 98-call method chain and a 98-term `+` expression each came back `JSON::NestingError` and were reported as files that could not be parsed, though prism found no error in them.
`JSON.generate` caps nesting at 100 by default and the tree adds one to three levels per AST level

## Status

**done** `ruby.mjs` `emit`.
Measured on Ruby 3.3.6 with json 2.7.2: the tree conversion runs out of Ruby stack near 2,000 levels while the uncapped encoder still generates at 1,500, so the existing SystemStackError rescue is what contains a pathological file
