# B61

Section: B. Engine

## Decision

The seven grammars are committed as `.wasm` files under `plugins/anatomiya/grammars/` beside a manifest of package, version, SHA-256 and ABI, and beside `LICENSES.md`, which carries each package's license. The grammar packages are dev dependencies of the marketplace at exact versions, and a gate holds each copy and the licenses to its package

## Why

The packages of the seven grammars are 173,972 KB on disk for 12,041,917 bytes of grammar: the rest is native prebuilds and C source.
Each declares `node-gyp-build` as its install script, and the Kotlin one lists `npm-check-updates` as a dependency.
Installed as dependencies of the plugin, all of that would land on every user, a Ruby one included.
A package's wasm is not always built from the source beside it: `tree-sitter-rust` 0.24.0 ships a `parser.c` at `LANGUAGE_VERSION 15` and a wasm that reports ABI 14, so the manifest records what the wasm itself answers.
`scripts/grammars.mjs --check` compares four things per grammar: the vendored file's hash with the manifest's, the installed package file's hash with the manifest's, the manifest's version with the root lockfile's, and the installed package's version with the lockfile's.
It also refuses a file with no entry, an entry with no file, and a link.
Each package is MIT, and its license asks that its notice travel with every copy; the copies shipped without one until 0.18.0, so `LICENSES.md` carries each license as its package ships it, under the version the lockfile pins, and `--check` refuses one that no longer matches. It is read off the packages and not the manifest, so a manifest fault is reported once.
It does not load a grammar: a test does, and compares the ABI.
`.gitattributes` marks `*.wasm` binary, so a checkout under `core.autocrlf` rewrites none, and a test asks git for the attribute on the manifest's first grammar.
It exits 1 where any of them fails and 2 on an argument it does not know, and it is a step of the `plugin` job in `.github/workflows/ci.yml` beside the three other checks `npm run validate` runs.
Given up: 12 MB in every clone and every install whatever language the user writes, and a grammar release is found by hand, since Dependabot is told to ignore the packages of the seven grammars
