# B46

Section: B. Engine

## Decision

An engine our own clock stopped before it reported a version is named as stalled, never sent to its install remedy

## Why

Measured: parse workers held at startup by a preload printed 'oxc reported no version: run ... setup' while `doctor` reported oxc 0.149.0 ok, and the pool's own reason, no ready answer in 20000ms, appeared nowhere.
A null version was read as a broken install whatever ended the engine

## Status

**done** `pool.mjs` (`stalled`), `ruby.mjs` (`stalled`, a child our idle or wall clock killed before its ready line on both attempts), `parse.mjs` (`engines[id].stalled`), `readiness.mjs` (`whyUnread`), read by `summary.mjs` and `render.mjs`.
The key is optional, so the facts schema did not move and an older record reads as no stall known.
