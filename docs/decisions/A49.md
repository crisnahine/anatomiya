# A49

Section: A. Delivery

## Decision

The paths a text names as `${CLAUDE_PLUGIN_ROOT}/...` are read by one function, `pluginPaths` in `scripts/validate.mjs`, and `scripts/shipped.mjs` and the hook test take theirs from it

## Why

Two gates read the same variable out of the same `hooks.json` with two patterns that disagreed about where a bare path ends: the manifest gate stopped at whitespace, the shipped-set gate at a backtick or a closing parenthesis too, and a third copy sat in `test/hook.test.mjs`.
On `sh -c "(node ${CLAUDE_PLUGIN_ROOT}/x.mjs)"` the first reported `x.mjs)` as a file the plugin does not ship and the second read `x.mjs`.
Every shipped hook is quoted, so the split was latent, and `LOADABLE` is already the same fact kept once for the same reason

## Status

**done** `pluginPaths` beside `LOADABLE`, with the wider terminator set and one alternation so a bare match never starts inside a quoted one; `scripts/shipped.mjs` keeps only its sentence-stop retry, which needs the tree; `test/validate.test.mjs` runs the subshell command clean and `test/shipped.test.mjs` pins the grammar and reads that `shipped.mjs` spells none
