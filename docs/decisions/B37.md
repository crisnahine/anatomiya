# B37

Section: B. Engine

## Decision

Each bridge refuses a guard name its own defaults do not carry, before anything is spawned: oxc against `GUARDS`, prism against `RUBY_GUARDS`, the checker against `SEMANTIC_GUARDS`, and the checker merges a partial bag over its defaults the way the other two do

## Why

`parseAll` refused a bag keyed by an undeclared language and never looked at the names inside, so `{ js: { maxByts: 1 } }` ran the defaults and reported nothing, which is the override-that-never-worked class the contract suite exists to catch (C17 and A26 record the same posture for the registry and for CLI options).
The checker took its bag whole, so one naming only `idleMs` armed the build window with nothing.
The refusal sits with each bridge because B24 keeps the numbers there
