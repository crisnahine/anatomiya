# C18

Section: C. The counted-claim model

## Decision

An obligation learns its producer root the same way C9 learns the companion root, scoped to one package, and a companion may vote only from inside that same package

## Why

Measured on decidim, a 28-gem Rails engine monorepo: `PAIRINGS` hardcodes literal top-level producer paths, and `companionOf` and `companionRoot` both gate on `rel.startsWith(`${from}/`)`.
Only the companion side was ever learned.
Every gem nests its `app/` one level down, so the producer set was empty for 7 of 9 pairings repo-wide, "ships with a" appeared in none of 339 generated files, and a brand-new spec-less model passed `check` with 0 MUST-FIX, 0 FIX, 0 NIT.
The one obligation this tool enforces rather than merely states went silent on exactly the repository shape it exists to catch, and nothing reported that it had not applied

## Status

**done** `pairing.mjs` (`companionRoot` takes a prefix, `packagedPairings`), pinned by `test/pairing.test.mjs`.
A package is a prefix under which `from` genuinely occurs in the corpus, found by scanning the corpus for the declared producer path appearing below the root rather than at it, with no vote: a prefix either holds an `app/models` or it does not.
C9's vote still runs, one step later and unchanged, to find that package's own `to` root.
The empty prefix is the flat repository and is exactly C9's original computation, pinned byte-identical against a flat corpus so nothing about that shape moves.
A companion may vote for a package's root only when it sits under that same prefix, so decidim-admin's spec of the same basename can never win the vote for a decidim-core model.
The root is a package too, the one holding everything not inside another: restricting only the named prefixes left it seeing every spec in the repository, and a nested package's spec then satisfied a root-level model with none of its own.
A package is named by a producer under it and never by a companion, or a repository mirroring its source tree under the test root reads that mirror as a package holding every spec it answers, which is whitehall's `test/unit/app/models` exactly.
Falling back to the declared pair mirrored under the package prefix when nothing lines up inside it keeps the same honest zero C9 established, now per package rather than per repository
