# B75

Section: B. Engine

## Decision

The reuse check's tree rule (B68) is measured by `scripts/measure-inert.mjs` against an oracle written apart from the rule's walk, which names what an added line of a left-out hunk may define, build or compute. The oracle tells a name, a type, a string's parts, a sign, a predefined type and a target by how the grammars spell them and by a node's own text, and every case of the rule's test is put to it line by line

## Why

An oracle that read the rule's lists would agree with the rule by construction.
It shares these keys of `tree-shapes.mjs` with the rule and no others: where a binding and its value are (`binding`, `declaration`, `value`, `alternative`, `collectionType`), which kinds a literal is made of (`literal`, `unary`, `collection`, `word`), `comment`, `interpolation`, `bareInterpolation`, and the definitions every reader of that table shares (`fn`, `cls`, `wrap`, `scope`, `annotation`).
A kind that is wrongly on one of those lists passes the rule and the oracle alike, so neither shows the mistake: that is what the sharing gives up.
It counts a binding where the binding starts, so it can miss a false ask on a later line of one and never excuses a skip.
Measured on the tree this row describes over the 21 repositories of B68: 34,075 hunks, 7,533 left out, 0 named by the oracle.
Against the tree before a write through a member or a subscript asked, 21 hunks moved to asked and none moved to left out.
32 mutations of how a target is read, in the rule and in the oracle, each turned a test red.
Holding the oracle to the rule's own cases means a list the rule gains and the oracle lacks fails the rule's test before any repository is measured

## Status

**done** `scripts/measure-inert.mjs` (`oracleHits`, `ORACLE`, `CONTAINERS`, `NAMING`, `ACCESS`, `NAMES`, `UNION`, `OWN_SIGN`, `OWN_TYPE`, `LITERAL_PARTS`, `COUNTED`, `measure`, `tally`), pinned by `test/measure-inert.test.mjs` and by `asking` in `test/inert-tree.test.mjs`.
`node scripts/measure-inert.mjs [--commits N] [--samples N] <repository> ...` reads each repository's last non-merge commits, asks the rule about every changed file of the seven languages as that commit left it, and counts files and hunks asked and left out; it asks git and checks nothing out.
The oracle re-parses every file holding a hunk the rule left out, a file asked about for another hunk included.
It names a function, a class, an accessor, a lambda, a call, an object creation, an interpolation, a conditional and a declaration with no body that hold a token on an added line, charged up to the statement or the member the token belongs to (`ORACLE`, `CONTAINERS`).
It names a string that holds more than its own text (`LITERAL_PARTS`), and a binding starting on an added line whose value holds anything but literals or which holds, outside its value, a node spelled as neither a name, a type, a modifier nor a pattern (`NAMING`, `ACCESS`).
It reads a sign by the literal's text in Kotlin and C# (`OWN_SIGN`), a predefined C# type by the language's keywords (`OWN_TYPE`), and `|` as joining types by the node's operator under a Python type (`UNION`).
It reads a Python or PHP target by its text (`NAMES`): names between commas inside a pattern's brackets bind, and any other target is named whatever its value.
An added line holding only closing brackets and separators is not charged, as under A91.
`asking` puts each line of a test case to the oracle as a hunk of its own: a line the rule leaves out and the oracle names fails, and so does a line that asks and the oracle does not name, unless the case lists it as unproven
