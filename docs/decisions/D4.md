## Decision

`distinct authors >= 2`, counted over files carrying conforming matches, **only when the area holds more than one directory**

## Why

Measured twice independently: the unconditional directory gate blocks 124 of 170 slots because area discovery finds leaf directories and a leaf directory has one directory
