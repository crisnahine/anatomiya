# A121

Section: A. Delivery

## Decision

Superseded: the overview head carries no house rule. It carried a fourth fixed sentence, `Code comments stay short and carry no ticket or issue number; a pull request takes its ticket's title, and where one ticket needs several, each opens with the part it changes, such as BE or FE`, and it is removed

## Why

The maintainer set it for every map on 2026-10-20: a ticket number in a comment goes stale while the commit that carries it stays, a long comment restates the code it sits on, and a pull request named after its ticket is found from either side; a ticket split across a back end and a front end needs the part in its title to tell its pull requests apart.
It is not measured the way A16 and A42 were, and the intake row `comment_ticket_free` was dropped as a counted claim because every measured repository held it near 1.0; this line states the rule rather than claiming a count.
The overview holds forty lines with every optional line on, so the head's new line is paid for by the Not covered section, whose string line now shares the line that says memory, GC and I/O are runtime only.
Superseded on 2026-10-24, when the plugin was opened to every repository: a rule one maintainer sets is not counted from the repository it lands in, so the line told every repository's agent one team's comment and pull request conventions.
A team that wants it writes it into its own `CLAUDE.md`.
The Not covered line stays shared, so an overview at its forty lines spends the freed line on the sections below the head, most often one more root in what lives where

## Status

**done** `render.mjs` (`overviewHead`) no longer writes it, pinned by `test/render.test.mjs` and `test/write.test.mjs`.
Not measured: whether an agent writes shorter comments or titles its pull requests this way because of it
