# B31

Section: B. Engine

## Decision

`minitestByPath`'s directory half trusts only the top of the tree: the file's first path segment, not any segment

## Why

`dir.split("/").includes("test")` fired on any `def test_*` under a directory segment named `test` at any depth.
Homebrew keeps its whole app under `Library/Homebrew`, and `Library/Homebrew/test/support/helper/test_each.rb` defines `def test_each` for a Sorbet-typed RSpec table-driven test with zero minitest APIs; that repository has no `Minitest::Test` or `ActiveSupport::TestCase` subclass anywhere.
The case the rule was built for stays caught: the `app/services` and `lib` files with an incidental `def test_*` have no `test` segment at any position, so the narrower check does not reopen the empire-flippers/api and discourse false positives it was written to close

## Status

**done** `facets.mjs` (`minitestByPath`), pinned by `test/facets.test.mjs`.
