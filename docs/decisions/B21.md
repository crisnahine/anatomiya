# B21

Section: B. Engine

## Decision

Every fact a language owns is one declaration in `plugins/anatomiya/lib/langs.mjs`, and the parse seam routes by the declared engine; no module past the seam names a language

## Why

Traced: a third language cost about 38 edit sites in 20 files, five of them copies of the extension facts (the corpus table, the worker's private grammar regex, `scratchExt`, the corpus bare-name regex beside the glob writer's array, the Flow-eligibility table), and the seam's own interface carried `rubyGuards` and a `dimensionsFor(["ruby"])` literal, so every caller had to learn one engine's name
