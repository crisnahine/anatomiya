# B21

Section: B. Engine

## Decision

Every fact a language owns is one declaration in `plugins/anatomiya/lib/langs.mjs`, and the parse seam routes by the declared engine; no module past the seam names a language

## Why

Traced: a third language cost about 38 edit sites in 20 files, five of them copies of the extension facts (the corpus table, the worker's private grammar regex, `scratchExt`, the corpus bare-name regex beside the glob writer's array, the Flow-eligibility table), and the seam's own interface carried `rubyGuards` and a `dimensionsFor(["ruby"])` literal, so every caller had to learn one engine's name

## Status

**done** `langs.mjs` (`LANGUAGES`, `declOf`, `language`, `grammarFor`, `placeTestsOf`, `assertKeyed`, load asserts), `parse.mjs` (`ADAPTERS`, `guardsFor`), `corpus.mjs`, `areas.mjs`, `scan.mjs` (`guards`), pinned by `test/langs.test.mjs` and `test/parse-contract.test.mjs`.

The dialect retry stays a question about the path alone, because a `.jsx` rel handed in under the `js` id is still a file the retry exists for, and narrowing it per declaration rejected files the old table retried.
The two scan gates read the declaration too: the semantic tier and the imports roster ask `langHas` instead of naming languages.
Every declaration also states two facts the component languages need (B52): `family`, the languages a test of it may be written in, and `embedded`, whose rules find its script blocks.
