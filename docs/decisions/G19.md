# G19

Section: G. Scope

## Decision

The reuse result is measured outside JavaScript, TypeScript and Ruby by one task per tree-sitter language, picked by a rule committed before any repository was scanned for it (`docs/measurements/2026-10-26-language-replication-rule.md`), and run as G18 runs every task

## Why

Every reuse task measured before 0.19.0 was JavaScript, TypeScript or Ruby, because the rule that picked them read the "most imported from here" line and only JavaScript areas had one; chef, consul, diaspora, errbit, fastlane, brew and huginn were passed over for having no such line.
From 0.19.0 every language has the line (H58), so the same kind of rule can pick a Python, PHP, Go, Java, C#, Rust and Kotlin task, and the README can say what the plugin does there from measurement rather than from the code

## Status

**done** the rule, committed in its own change before its picks and their scenarios.
