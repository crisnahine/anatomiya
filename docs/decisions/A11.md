# A11

Section: A. Delivery

## Decision

A scan of a repository with no tracked source says how many source files are untracked, counted by the same filters `collect` applies

## Why

The corpus is tracked files, so a repository whose first commit has not landed got an empty map, exit 0, and an overview stating that 0 files were uncovered while five sat on disk.
The count is shown beside "commit them and scan again", so a file a later scan would drop must not be in it
