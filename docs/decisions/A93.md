# A93

Section: A. Delivery

## Decision

A linked worktree with no map of its own is answered by all three hooks from its main checkout's map and record, under the main checkout's name. `check` does not borrow: its no-map caveat names the main checkout and says to scan the worktree

## Why

This overturns A24's boundary silence for one shape. v0.2.5 refused the enclosing checkout's map because it arrived stamped as this code's own, on a branch the counts never described; the stamp now names where the counts came from, and the silence was measured costing more than a labelled count.
A worktree carries only what is tracked, so a repository that ignores `.claude/` gives every worktree nothing.
Measured on a front end where all four worktrees had no map, both hooks answered `{}` in each, and a session working in one wrote a spec into a `__tests__` directory the main checkout's notice names as having no precedent.
The stamp also says the area files it names are there and not in the worktree, since Claude Code 2.1.280 loads no rule file from the main checkout into a worktree, by design; the notice ends with the same, and the write is still judged against the worktree's own files.
The end-of-turn check prints no counts, so it takes the record as its gate and adds no line.
`check`, which compares a branch against a map of its own, does not borrow: in such a worktree its no-map caveat names the main checkout and says to scan the worktree.
It is followed only as git registered it: the registration has to sit in the main repository's own `worktrees/` and point back at this marker, so a copied marker, or one shipped in an archive beside a forged registration naming another repository, keeps the silence; that second route read another repository's record where a linked `.claude/anatomiya` is refused.
A submodule has no `commondir`, and a git directory not named `.git`, which is a bare repository, `--separate-git-dir` and a `.git` symlinked elsewhere, names no checkout without reading `core.worktree` out of git config, so those keep the silence too.
Nothing else reaches a worktree made by hand: Claude Code 2.1.280 copies ignored files only into worktrees it creates itself, through `.worktreeinclude`.
`docs/research/why-a-worktree-got-no-map.md` holds the sources and the measurements
