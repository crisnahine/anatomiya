# C58

Section: C. The counted-claim model

## Decision

The scan's claims line counts a stated co-change claim an area file carries as stated, in the stated count and in the total, and so does the overview's `N stated`; one no area file carries counts in neither. Its last clause says what is left: nothing past none, `, the other prints as a count` for one beside a stated or default-matching claim, `, it prints as a count` where that one is the only claim, `, the rest print as counts` for more, and `, they print as counts` where nothing else was stated or matched

## Why

The line read `0 of 4 claims stated` while an area file stated a co-change claim.
A claim no area file carries is said by the notice and the check only, so it is not one the map states.
The constant clause `the rest print as counts` was false at none left, where `3 of 9 claims stated, 6 match the model default` had nothing left, and at one.
The line is terminal only, so no map moves for the clause; counting the printed co-change claims moved rubocop's line from `33 of 104 claims stated` to `40 of 111`, consul's, mastodon's and canvas-lms's by one each, and whitehall's, forem's and supabase's by two each
