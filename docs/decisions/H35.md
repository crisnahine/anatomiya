# H35

Section: H. Layout

## Decision

A Ruby file named `_spec.rb` or `_test.rb` is a test only where a test tree also says so. The dotted and hyphen forms still answer on the name alone

## Why

The third narrowing of the name rule, beside H7 and H29.
The Ruby form is the one a producer wears in earnest, and a file outside every test tree has an address available to corroborate it.
Measured across the 35-repository corpus and one Rails map, eight files move in five repositories and seven of them are plainly not tests: a RuboCop cop named for the `Rails.env.test?` guard it enforces, which printed a test group of its own in the file that loads every turn and told a reader to write the next cop with a `<cop>_test.rb` beside it; four Homebrew classes, `SoftwareSpec` and three `T::Struct`s, each of which has its own `*_spec_spec.rb` under `test/`; a one-line Cucumber support file; and a CI driver script that invokes the suite rather than being one.
The eighth, a hand-run integration script with its own assertions, is a real false negative and is accepted at one file in a 694-spec repository.
The largest candidate population in the corpus, 40 files under `gems/plugins/*/spec_canvas`, moves nothing, because every one of them answers on what the file itself says before its name is read.
What this still does not do: it does not require an example, which H29 refuses on measurement, and the dotted and hyphen forms answer on the name alone because discourse writes 4,000 tests as `login-test.js` and nothing else in them says so
