## Decision

A tree that came back from the Flow retry does not answer the dimensions that depend on the annotations, and each such row says so on itself

## Why

The retry blanks the annotations so oxc will take the file, and three rows then answer off a tree with the thing they ask about deleted.
Measured on react before the guard: `explicit_return_type` inverted from 986 of 1213 conforming to 0 of 1213, and the check printed `FIX exported functions declare their return type` next to a line that declares one, quoting the annotation in its own snippet.
`type_only_import` reads the type positions the stripper removes.
`import_extension` never reads a type, and is blind for a different reason: a type-only import is one of its sites and the stripper deletes the whole statement, so react's 309 of them, not one of which carries an extension, vanished and the file read as more conformant than it is
