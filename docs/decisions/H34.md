# H34

Section: H. Layout

## Decision

The empty-tail mirror is asked in both directions, held to a candidate whose top segment is a tree the repository keeps tests in

## Why

`mirrors` is one-directional and the empty-tail arm only ever asked whether the candidate ends in the root, so a root whose tree-less form is longer than the test tree's never matched.
`app/widgets` is a Rails autoload root, `withoutTree` leaves `widgets/widgets` against `widgets`, and every file sitting directly in `app/widgets/widgets` read untested while the same files read tested one segment up: `0 of 13`, `0 of 11`, `0 of 8`, `4 of 22` and `3 of 11` against true figures of 1, 3, 2, 16 and 6, and a roster line of 54 of 115 against 57.
That breaks the invariant two pins already hold, that a file answers the same whichever root above it is evaluated, on a trigger neither covers.
H18 named one accepted hole, a source root whose own name is a tree word, and did not name this one.
The reversed direction is where a false positive would come from, so it is guarded twice: `tail === ""`, which is load-bearing rather than tidy since `rootBare` is null on the nested path and the reversed call puts it in the receiver position, and the candidate's own top segment being in `TEST_TREES`.
Measured with `measure-layout.mjs` over the whole corpus, which is the oracle H18's own throwaway probe left behind, at 6,849 areas of which 4,886 carry a companion count: 24 areas gain and none drops on this row's own account, every gain hand-verified, and every roster namesake line byte-identical outside the two repositories the defect was found on.
H37 is the guard that measurement forced and accounts for the six that drop.
Knowingly accepted and unmeasurable from the corpus, which holds no case: within one engine, where `assignOwners` cannot decide, `app/services/models` can still be credited from `spec/models`.
Two ways it cannot: the tails tie, or it never looks, since it buckets by `language` where the loop now filters by engine, so a `.ts` test against `.tsx` sources finds no bucket at all
