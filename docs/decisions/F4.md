# F4

Section: F. Safety

## Decision

Every repository-controlled value goes through F3: paths, area names, author names, commit subjects, branch names, matched source text

## Why

## Status

**done** `encode.mjs`, and one pass per record rather than one per line at the two writers a machine reads: `check-report.mjs` (`encodeReport`), `summary.mjs` (`encodeScan`, `encodePin`).
Paths are the exception in every record: `encodeReport`, `encodeScan` and `encodePin` take every path field (the check's root, rows, finding paths and rules lists; the scan's root and rule file lists; the pin's area and file paths) through `locator`, which removes only what breaks or reorders a line, anything outside letters, marks, numbers, punctuation, symbols and the plain space, and neither caps nor script-checks.
Every check writer hands the path to something that opens the file: through the display encoder a long monorepo path ended in `…` and a Japanese directory became a placeholder, so GitHub could not place the annotation and a JSON reader could not join the finding back to its file.
The rendered lines had always encoded, so a record was the one surface a crafted filename reached whole: `JSON.stringify` escapes neither a bidi override nor a zero-width joiner, and the pin's `added` list is printed by its JSON writer and by nothing else, so no encoded counterpart existed for it anywhere.
An argument the command line refuses is not the repository's, and it is printed back to a terminal, so it takes the same pass: `refuse` in `plugins/anatomiya/bin/anatomiya.mjs` puts the sentence that quotes it through `locator`, and a refusal that is thrown is printed a line at a time through it.
Run: `scan . --format` with an escape byte and a line break in the value prints `unknown format: x [31m RUN` on one line with the usage under it, exit 2, and `scan` of a path spelled that way prints `anatomiya: no such directory: /nonexist [31m/pa RUN`, exit 1; `test/cli.test.mjs` holds both, for an unknown command, option, format and target and for a path and a `--base` that resolve to nothing.
The scan and pin records went through the display encoder until 0.11.2, so a root past 120 graphemes ended in `…`, a mixed-script root became the placeholder, and two long file paths in one pin directory came out as one string.
