# H43

Section: H. Layout

## Decision

A file named like a companion answers an obligation only where the tests line would count it as a test file, and a producer's namesake elsewhere is matched on its path tail below the root

## Why

The pairing rows read paths only, so H29 and H35 stopped at the tests line.
On a measured Rails API one RuboCop cop named `freeze_time_outside_test.rb` put 'a model ships with a test: 0 of 129' and '0 of 37' into an RSpec-only map.
A spec commented out top to bottom credited its service, so one area file printed '3 of 28 have a namesake test' above '4 of 28 sites'.
The elsewhere count matched on basename: 142 across 44 lines on the same map, nearly all unrelated specs sharing a name like `create_spec.rb`.
Matching on the tail, as `companionRoot` already votes, takes it to 0 there.
The check applies the same filter, with the parses of the files the branch wrote, so an empty spec added beside a model does not satisfy it
