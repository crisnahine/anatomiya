# A96

Section: A. Delivery

## Decision

An area's `paths` also stays off the tracked source the corpus left out: files under an excluded directory, generated files, and source spelled in another case (A10)

## Why

A10 held only over the counted files, and G7's exclusions were missing from the tree the cover was built from, so an area with a `fixtures/` or `test_cases/` inside read as owning its whole subtree, and its one recursive glob delivered its sentences to the code G7 keeps out of the counts.
Measured: angular's compliance area counted 8 files and reached 2,017.
Across 7 corpus repositories the globs reached 2,017 (angular), 1,707 (react), 591 (prisma), 43 (webpack) and 36 (canvas-lms) left-out files

## Status

**done** `corpus.mjs` (`collect` returns `uncounted`, `excludedAt`), `areas.mjs` (`reachable`, `byExcludedName`, `withLeftOut`, `leftOut`, `globsReach` reads the by-name tail), `scan.mjs`.
A generated file beside counted ones is negated by its own name, and a directory holding only left-out files is negated like a foreign subtree.
Neither costs the recursion: a subtree whose counted files are all the area's keeps its recursive glob and takes the negations, since one generated file at the root otherwise tied the one-level shape and a directory added after the scan lost the map.
An excluded directory is negated once by its name at any depth, because every file under that name is left out wherever it sits: cut out one directory at a time, prisma's `_fixture/` beside each of 102 functional tests took one area to 106 patterns in a 40-line file.
Not where the name also sits on a counted file's path (`build` under `src`).
Re-measured at discovery over all 35 corpus repositories: the old globs reached 16,311 left-out files in 24 of them (8,512 on babel, 1,601 on next.js), and now 0, with the same partition in every one and 232 more patterns (12,237 to 12,469).
A file name in a pattern goes through the path encoder like a directory does, and a name that cannot be spelled leaves the cover at its recursive fallback.
