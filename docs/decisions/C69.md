# C69

Section: C. The counted-claim model

## Decision

`class_inherits` asks Python, PHP, Java, C# and Kotlin which class a class declaration names as its base, by the base's last segment and without type arguments, learned per area as `class_base` and `extends_base` are. Go and Rust have no class to inherit. Kotlin, refused by the bar, is asked by C71, as the supertype a constructor is called on

## Why

The question was asked of JavaScript and Ruby and had never been measured over the tree-sitter languages.
On the repositories of C51 and C54, by their bar, every one of the four clears it: Python 0.3953 to 0.6667 (spread 0.2714), PHP 0.5592 to 0.8571 (0.2979), Java 0.3864 to 0.6735 (0.2871), C# 0.3319 to 0.7500 (0.4181), every repository under 0.90.
Kotlin, read as the delegation specifier that calls a constructor, spread 0.1416, short of 0.15; C71 asks it anyway.
Python's `object` names no base anybody chose, and a keyword argument such as `metaclass=` names no base at all.
A C# base list puts the base class first only where there is one, so a first entry named like an interface, `I` and a capital, is taken for one: what this gives up is a base class named that way.
`Base[T]` is read by its subscript's value, which a first build read as `T`; the fixture holds it.
