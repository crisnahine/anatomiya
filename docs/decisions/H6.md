# H6

Section: H. Layout

## Decision

C7 is unchanged. The pairing obligations keep their null counter-claim and the roster carries the absence as a count instead

## Why

`0 of 40 have a spec` is a fact about a directory; a directive telling an agent to write specs where nobody writes them is a sentence nobody measured.
The count prints whenever the repository holds any test file at all and the root's top printed extension is one this tool parses, so a root whose largest is images or data is not asked.
That is the line the api side needed: workers ship no spec, services do, and nothing in the map said so, because an obligation treats a missing companion as an absence rather than as a habit.
The namesake is matched on the path tail the way C9 learns a companion root, and the root the namesakes share is named by a count of votes rather than by the first match.
The tail is asked twice, whole and then with the seven tree names dropped from both sides, because a repository that splits a source tree from a spec tree writes the same path on both halves and only the word for the tree differs: openproject's `modules` read 0 of 2623 with `budgets/spec/models` sitting beside `budgets/app/models`, and a mirrored match votes for the tree the two paths part on.
A top vote under half the matched files names no root at all, since one `__tests__` per component directory answers every file and names no one place.
A root that is or sits under a test tree at any depth, `test`, `tests`, `spec`, `cypress`, `e2e` or `__tests__` matched against every path segment rather than only the first, is not asked at all: its support files are what the tests run on, and webpack's `test` read `1 of 7858 has a namesake test under test` over the fixture modules its 2,607 tests exercise.
The first-segment reading was right for a single-project repository and silent on every monorepo, where the first segment is the package name: fastlane's `gym/spec` stated `1 of 1 has a namesake test` over a single zero-byte `spec_helper.rb` credited through an unrelated gem's same-named spec, and decidim's `decidim-dev/lib/decidim/dev/test` scanned 46 files of shared RSpec tooling as application code with 7 false credits.
The webpack citation is unchanged, since `test` is still caught at its first segment under the any-segment reading
