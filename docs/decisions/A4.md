# A4

Section: A. Delivery

## Decision

The overview says how many files we generated and names the other `.md` files in `.claude/rules/`; the check and the scan name them too. Every one of the three listings is bounded, at the budget its surface can afford (F17)

## Why

`.claude/rules/` is a *repository* directory.
A cloned repo can ship a rule file with no `paths` key that loads unconditionally from the moment of clone, in our house style, forever

## Status

**done** `render.mjs` `check.mjs` `write.mjs` `summary.mjs`.
This row asked for the enumeration on the other side: every file we generated, so any other one is identifiable by absence.
Measured against A9, that is 4 KB of hex filenames added back to the file that loads on every turn, on the repositories where nothing is wrong.
Naming the others instead is the same guarantee at zero cost when clean, it names the file a reader would otherwise have to go and find, and it reaches the reader in the file that is loading beside it.
The overview names up to six and counts the rest, because past a handful the fact is that the directory is somebody else's and the names stop being the useful part; the check and the scan are read once rather than every turn, so they name twenty.
The overview names only the files this tool did not write and gives its own leftovers as a count, since the reader's move is the same whichever of those it is and that section is paid for on every turn.
Both surfaces now also split "somebody else wrote this" from "we wrote this and no map names it": the check reported the first only, and by prefix, which called a hand-written `anatomiya-notes.md` ours
