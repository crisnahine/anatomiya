# A102

Section: A. Delivery

## Decision

The same map can also be written for Cursor, as `.cursor/rules/anatomiya-*.mdc`, and for GitHub Copilot, as `.github/instructions/anatomiya-*.instructions.md`, and only where that target is on. This amends A1 and A25

## Why

`scan --targets cursor,copilot` turns a target on, and it stays on while its own overview file is in its directory and is this tool's, so a clone that brings a committed overview has the target on with nobody asking there.
A scan killed while turning a target off leaves that overview behind with the record naming it under `removing`, and a target whose overview the record names there is off to the next scan that names no target, which finishes the job.
Nothing else remembers the choice.
`--targets` names the whole set, so a set without a target turns it off, and `claude` is in every set.
Cursor 3.20.21 does not read `.claude/rules/`: the string appears 0 times in the 8 bundles of its client.
By GitHub's documentation, Copilot on GitHub.com gives path-specific instructions to its cloud agent and to code review only, and they read `.github/instructions`.
So the map did not reach Cursor at all, and of the Copilot surfaces read it reached only VS Code (A106).
Off until a scan names it, because each of the two is a directory people write in by hand, and A1's reason for one directory holds for everyone who does not ask.
The file is the switch because the refresh (A95) calls the scan with no option and has to write the same set, and a second record of the choice can disagree with the directory: the exclude line hides `.claude/anatomiya`, so a clone can hold a committed copy and no record of it, and an option kept in `.claude/anatomiya` would read off beside files that load.
Read off the overview, the state is what the reader of that directory already sees.
Deleting the overview by hand turns the target off, and the next scan removes the area files the record names.
Measured against the 0.13.4 release on six scratch repositories that name no target, each plain, with hand-written files planted untracked in both directories, and with the same committed, 13 commands per run: exit code and stderr matched in every step of all 18 runs, and no file outside `.claude` differed.
All 18 differ in five things this release changes for every repository: the record's `semantic` gains `carried`, `measuredAt` and `measuredUnder` (B8), `layout.json` stamps the record's size, the stamp in `refresh.json` moves, `doctor` prints a tree-sitter line, and `check --format json` gains `missingGrammars`.
8 of the 18 differ in nothing else.
The other 10 differ only where the changelog lists a change for this release: Vue files read and the scope clause in the 3 runs of the mixed-language repository, the roster leaving out a committed map in 3, and the roster leaving out a hand-written file committed at `.cursor/rules/anatomiya-overview.mdc` in 5, one run showing both roster changes (H7)
