# C44

Section: C. The counted-claim model

## Decision

A constant a library defines as another's alias is the same constant: `Sidekiq::Worker` and `Sidekiq::Job` vote as one class and conform as one, and the claim names the spelling the area writes more. The check decides a learned row through `sameConstant`, the fold's own test

## Why

Sidekiq's `worker_compatibility_alias.rb` reads `Worker = Job`.
Recorded raw, `include Sidekiq::Job` in one of rails-api's 11 areas stating Sidekiq::Worker was a MUST-FIX asking for the legacy alias, which changes nothing at runtime.
The check compared with `===` while the fold used `sameConstant`, so a mixin written relative to its namespace (C30) conformed in the map and was a MUST-FIX in the check
