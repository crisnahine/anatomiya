# A105

Section: A. Delivery

## Decision

In those two directories a file this tool did not write is never written over. Where a target is named, an entry in the way refuses the scan; where it is merely on, the entry stays and that area has no file there

## Why

An entry whose name differs from a planned name only in letter case takes that name, unless the listing holds both spellings.
Leaving a target out of `--targets` removes only the names a scan gives a file, and only where the file carries the key, whether or not the record lists it and whether or not this run holds its area.
`.cursor/rules` and `.github/instructions` are where people write rules by hand, so a name there is not this tool's by construction, as a generated name in `.claude/rules` is (A1).
Naming a target is consent to write it, not to replace a file the audit just classed as somebody's, so the scan refuses with the file named: `.cursor/rules/anatomiya-overview.mdc was not written by this tool, so .cursor/rules could not be written and nothing was written anywhere: move or delete it and scan again`.
A refresh has nobody to read a refusal, so a target that is merely on leaves the entry, plans no file at that name, and lists it.
Somebody's entry is a file with no key, a link whatever it leads to, a file that will not open, and a directory or a fifo.
A directory, a link or a fifo under the `anatomiya-` prefix is listed at any name, planned or not and with the target on or off, so a directory at an area's name is counted when its target is turned off.
Case, measured on APFS: a write to the planned name lands on a hand-written `Anatomiya-Overview.mdc`, and the volume folds the long s onto `s` as well, so two names are compared after upper-casing and then lower-casing both.
A listing that holds both spellings proves the volume tells them apart, and nothing is held there: applied on every volume, the rule refuses every scan of a case-sensitive directory that holds this tool's overview beside a person's capitalised one, where nothing collides (measured on a case-sensitive disk image).
Turning off by name does not ask the record, because a clone can hold the committed files and not `.claude/anatomiya`: held to the record there, three runs of `--targets claude` removed nothing and the target stayed on.
It asks the name, the overview's or `anatomiya-area-` and eight hex digits, so a keyed copy somebody kept as `anatomiya-my-notes.mdc` stays.
Off is none of this tool's files left in the directory, so the file of an area this run holds because it could not read its language (B41) goes with the rest: holding decides whether a file is rewritten, and has no bearing on whether its target is on.
Kept, `--targets claude` printed `.cursor/rules is off now` beside an area file that stayed in the directory.
`.claude/rules` is always on, so a held file there stays.
A plain scan keeps A3's three facts
