## Decision

Where only the import edge answers, a suite inside the root being counted beats one outside it

## Why

Neither candidate is structural, so both are true and only one is the answer a reader wanted: `e2e` beat `pkg/hooks/__spec__` on the letter `e`.
H25 left this open on purpose, because ranking test directories against each other is a heuristic with its own failure modes, and asked for a measurement first.
The measurement: five roster roots print a namesake root that came from the edge fallback at all, one of those has two or more directories reached that way, and none has one of them inside the root.
The corpus holds no case, so the preference changes no line it prints; it settles a shape the corpus does not contain and is worth no more than that.
Ranking on anything more than inside-or-outside is still unbuilt and still wants its own evidence
