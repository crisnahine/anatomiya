# G13

Section: G. Scope

## Decision

Every A/B trial starts from one commit in an arm that is not a linked worktree. It sees only its own tools, the arm's project settings and this repository's plugin, and it is scored on what it wrote even when cut short. A trial that finishes and writes nothing is counted apart, with the first line of its answer as the reason

## Why

Measured on 2.1.285.
Built once and never reset, trial 2 found trial 1's file, wrote nothing and was dropped.
Arm B as `git worktree add` got its main checkout's map through the 0.10.1 fallback, so every run with the plugin enabled aborted at the probe.
`--allowedTools` only approves, so Bash ran `cat`.
With no settings-source list, both arms read the operator's CLAUDE.md, plugins and MCP servers.
The turn cap exits 1 after a successful Write, and 7 of 7 capped trials on two saved runs were in the map arm, whose Stop hook spends the turns, so dropping them skewed one side.
Shared clones still borrow the object store, `project,local` keeps the map (the `''` trap in G11), and `--plugin-dir` puts the plugin back the same way in both arms.
A naming row narrowed to one kind of file is scored over that kind, as reduce and check already do.
A trial that finished clean and wrote nothing showed only as a lower "trials that wrote a file" count, while its answer ("The file already exists") said why, so the log line quotes that answer and the result has a row for the count
