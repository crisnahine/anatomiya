# B74

Section: B. Engine

## Decision

The tree rule of the reuse check (B68) asks wherever it cannot prove that nothing runs, and six kinds of line ask by choice: a binding that holds anything but names, types and literals outside its value, a string holding more than its own text, a sign the language does not define for the literal after it, a C# literal declared as a named type, a write through a member or a subscript in Python and PHP, and any token that is not a closer

## Why

A list of the kinds that ask leaves a wrong skip behind every kind nobody listed, which is how two earlier rules of A91 broke; listing what computes nothing costs a false ask where a grammar gains a kind.
A write through an attribute or a subscript runs the object's own protocol with no call written: a property setter or `__setattr__`, `__setitem__`, and PHP's `__set` and `offsetSet`.
The other five languages bind only by declaration, so `this.x = 1` asks there already, as `obj.x = 1` does under the JavaScript rule.
Python, PHP, Go, Java and Rust cannot bind an operator on a built-in literal to code somebody wrote, so only Kotlin and C# list which sign goes with which literal.
None of the seven but C# converts a literal to a user's type with no call written, so only C# reads the declared type: that was run for Python, PHP and Go, and ruled by reading for Java, Rust and Kotlin, with no compiler for them on the machine.
The false asks this accepts, counted over the 34,075 hunks of B68, each costing one search.
A write through a member or a subscript that reaches no code somebody wrote: 21 hunks, 15 of Python and 6 of PHP, which are twelve attributes set in a constructor or a method, three settings written on an object in a test, four dictionary or array entries and two static properties reset in a test.
Three of the 21 do reach a setter: a multiprocessing `Value`, a descriptor, and `os.environ`.
A token that is no closer: 12 hunks, an `else`, an `except:`, a `})) {`, or an opening bracket on a line of its own.
A C# enum member: 2 hunks.
A C# enum given `0`, a field typed `System.Int32` or `dynamic`, `-1u`, a keyed PHP pattern such as `['k' => $a] = [1];`, and a comment inside a pattern: no hunk.
Given up: `Foo f = null;` in C# where `Foo` is a struct that converts from a reference type is left out, and so is `const Money D = 5;`, which no compiler accepts where a conversion would run

## Status

**done** `inert-tree.mjs` (`inertBinding`, `inertDeclaration`, `binds`, `converts`, `plain`, `isLiteral`, `paired`, `textOnly`, `CLOSER`), `tree-shapes.mjs` (`SHAPES`, under the keys `part`, `target`, `bound`, `literalPart`, `union`, `signed`, `negated`, `inverted`, `declared`, `builtin`, `nothing`, `closes`, `statement`, `counted` and `countedPart`), pinned by `test/inert-tree.test.mjs` and `test/tree-shapes.test.mjs`.
A binding outside its value: every named node in its target, its pattern, its type and its modifiers, and in the declaration around it, is a literal or a kind the language lists under `part`, so `const A: [u8; f()] = [0; 3];`, `int[F()] e = null;`, `var x = [size()]int{0}` and `x: a + b = 1` ask.
An operator between types passes only where it is `|` in a Python annotation (`union`).
A binding with an annotation on it asks, and so do one with no value outside a counted Go group, a Rust `let` with an `else` block, and a declaration holding anything but its bindings, its modifiers and its type.
A string: every part of it is its own text (`literalPart`), so `$a = "${foo()}";` and `A = f"{{{x}}}"` ask.
A sign, in Kotlin and C#: it is part of a literal only before what the language pairs it with (`signed`, `negated`, `inverted`), so `-1` and `!true` ask nothing and `+"a"`, `!1`, `-1u` and `!null` ask.
A C# literal under a named type: `int a = 5;` asks nothing and `Money a = 5;` asks, since the type may hold an `implicit operator`; a `const` and a `null` ask nothing under any type (`declared`, `builtin`, `nothing`).
A Python or PHP assignment binds only where its target is a name or a pattern of names (`target`, `bound`): `x = 1`, `a, b = 1, 2`, `$x = 1;` and `[$a, $b] = [1, 2];` ask nothing, and `a.b = 1`, `self.x = 0`, `CONFIG["k"] = 1`, `$a->b = 1;`, `$a['k'] = 1;`, `$a[] = 1;`, `self::$x = 1;` and `$$x = 1;` ask.
A PHP assignment binds only as a statement of its own (`statement`), so one written as an argument asks.
A token asks unless it is `)`, `]`, `}`, `;`, `,` or `#endif` (`CLOSER`): `get`, `func`, `function` and a lambda's `{` each open a callable with no name on their line.
A Go constant counted off `iota` holds `iota`, literals and operators and nothing else (`counted`, `countedPart`), so `T(iota)` asks
