# A6

Section: A. Delivery

## Decision

Each generated file stays under ~40 lines

## Why

Measured: a rewrite does not re-attach inside one context window (A17 qualifies "session" here, and the bound is unaffected: the window is the unit a long stretch of work happens in); the change notice truncates head and tail, so a mid-file edit reaches the model in neither copy

## Status

**done** `render.mjs` (`MAX_LINES`, `areaListing`, `settle`).
It was a hope about how many dimensions an area holds, and thirteen stated JS claims already clear it.
An area file drops its counts before its directives and says how many of each kind did not fit; the overview's listing takes whatever the rest of the file leaves.
The `paths` list is exempt, because a glob dropped to save a line mis-delivers the whole file, so the bound is measured over what a reader reads.
The 40 lines are the `.claude/rules` file's: a Cursor or Copilot file holds the same body and carries its own lines on top, so an overview there runs to at most 43 lines and an area file to at most 43 (`mostLines`, A103).
Measured across 35 repositories: 17 hold an area whose cover alone runs past forty lines, the worst at 170 patterns on canvas-lms, and every one of those bodies came to ten lines or fewer.
What overflows is the routing, and it sits above the directives rather than around them, so the reading stays in the tail, which is the half a change notice keeps.
An area needing 170 negations to be spelled exactly is a question for A10 rather than for this row
