# B44

Section: B. Engine

## Decision

An installed prism is loaded only after its paths answer the chosen version for this interpreter; otherwise the next newest, then the default

## Why

Measured after a Ruby upgrade with a shared gem directory: a prism built for the old Ruby stayed listed, was put on the load path, failed to load against the new libruby, and `doctor` said prism was not installed, hiding the accurate "older than 1.0.0".
A listing says a gem is installed, not that its native extension was built for the interpreter that will require it

## Status

**done** `ruby.mjs` `prismLoadArgs`, `loadedVersion`.
The load check runs with the same bounded, scrubbed, out-of-repository spawn as the listing (B24), and `choosePrism` stays a pure function of the listing
