# G14

Section: G. Scope

## Decision

`check:docs` holds a bare `.mjs` name in a Status marked done to the file names the tree holds, and reads every count phrasing through one number-word table, zero to ninety-nine: a compound read whole with a hyphen or a space and either case on each half, and `no`, `none` and `zero` read as 0. It reads `N grammar files`, `N grammar packages` and `the N engines` beside the older phrasings, and a bare `N engines` in every stating document but the decision record

## Why

A Status names most modules bare, and the gate read only names carrying a directory, so a renamed module named bare passed: on the table as 0.14.0 shipped it, 700 bare `.mjs` names, one of them missing from the tree and an example (`defaults.mjs`, H25), beside 68 bare names of other suffixes; with the 0.15.0 rows, 771 bare `.mjs` names and the same one missing.
Counts written as words passed unread: a per-language count in words, a count word past thirteen, a total of grammar files or of engines in words, and a hyphenated compound was read as its last word, twenty and three as three.
Of the bare names of other suffixes almost all are example names from scanned repositories (`tsconfig.json`, `Foo.test.ts`), so the rule stops at `.mjs`, with that one example allowed.
"N dimensions" stays digits only: the README spells shares of dimensions in words, and the total is always a numeral.
A build contract row says "spans two engines" of a pair it compares, so the record, its index and its row files, is not read for a bare count of engines

## Status

**done** `scripts/check-docs.mjs` (`doneFilesGone`, `DONE_BARE`, `DONE_EXAMPLES`, `NUMERALS`, `counted`, `N`), pinned by `test/check-docs.test.mjs`.
Given up: a renamed `.json` or `.md` of ours named bare in a done Status still passes, a phrase word in another case ("for javascript") is not read, and a stale engine total in a row passes unless it says "parser engines"; the other way, ordinary prose in a count's shape fails and has to be reworded: `the one for` before a language, `no` before `grammar packages`, `the two` before `engines` outside the record.
It also parses every invocation of the binary the documents spell, through `${CLAUDE_PLUGIN_ROOT}` or as `plugins/anatomiya/bin/anatomiya.mjs`, by the CLI's own argument rules, in the README, `CONTRIBUTING.md`, the top-level docs and the command files.
