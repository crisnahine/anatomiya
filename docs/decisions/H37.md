## Decision

A test file is evidence about a source file only where the two run on one engine, asked of the candidate rather than of the branch that matched it

## Why

The rule was written on one branch, the bare-basename pair at the top of two trees, and every other path to a match went without it. mastodon keeps a `spec/models` of Ruby specs beside a `spec/javascript` of TypeScript tests and holds a model of each name in both languages, so the mirror credited each with the other's files: `app/javascript/mastodon/models` read 8 of its 17 off the Ruby specs, and `app/models` read the TypeScript tests.
Measured over the whole corpus, six areas were carrying such a credit before this row and none is left: discourse charged four directories of `.gjs` components to Ruby RSpec system specs, one of them naming `plugins/chat/spec/system` as the place its JavaScript is tested, and decidim charged two directories of `app/packs` JavaScript the same way.
A tail that mirrors is evidence about a shape, and a shape two languages share is a repository that keeps both there rather than a test.
The engine and not the language, which is finer than the question: `language` separates `.tsx` from `.ts` because that is the grammar the parser is asked for, and a component tested by a plain `.ts` file is the ordinary shape in every React repository there is.
Measured either way over the corpus, no area moves between them, so this costs nothing today and states the rule that was meant.
The bare-basename branch keeps asking `language`, because it is the one match with no structure behind it at all
