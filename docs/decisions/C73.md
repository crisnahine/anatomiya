# C73

Section: C. The counted-claim model

## Decision

A row that asks nothing of a test file declares `outsideTests`, and one that keeps off a whole test tree, whose files stand in for the code under test, `outsideTestTrees` on top; the walk hands such a row no node of the file by the one rule `outsideTests` in `test-shape.mjs`, beside `isTestFile`, which moved there from the roster, and the file stays eligible

## Why

Seven rows skipped test files by four spellings in three row files: the JavaScript URL row by the path alone with its family written in, the Rails route row by the directory alone, five tree-sitter rows by the facets and one of them by the directory as well, and the tree row file imported the roster's `isTestFile` for it, which put `layout.mjs` and `companions.mjs` into every tree-sitter parse child.
The three siblings of one question (C72) could not be held to one exclusion while each spelled its own.
Folding the rule into `asks` would have moved every such file out of the eligible files and changed the applicability gate; skipping the row's walk keeps today's denominators, which the 12-repository corpus oracle confirmed byte for byte.
