# A12

Section: A. Delivery

## Decision

An area's `paths` carries one pattern per bare filename it holds, beside the extension glob

## Why

A brace of extensions cannot spell `Rakefile`, so admitting a file with no extension reopens A2 from the other side: counted and never delivered.
Emitted per cover entry, so a negation cuts the bare name out of a foreign subtree exactly as it cuts the extension glob, and only for names the area actually holds

## Status

**done** `areas.mjs`.
The pattern stays in its two halves, `dir` and `tail`, all the way to the renderer, so the joined form is never taken apart again by a second reading of the grammar
