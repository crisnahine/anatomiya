# D7

Section: D. Gates

## Decision

Counts print whether or not a directive fires, and `gate` records which one suppressed it

## Why

Makes a wrong threshold cost one sentence

## Status

**done**, and bounded by A6.
A6 gave the area file a hard line budget, and a count is what gives way when it runs out: a directive is what the file exists to deliver, and an area holding more slots than fit has to drop one of the two.
`gate` is recorded either way, in `facts.json`, which is where a threshold is actually audited from; the printed line is the convenience.
The truncation notice says how many of each kind went, so a reader is never left guessing which, and it counts the stated ones off the same array `droppedSlots` reads.
Two derivations of that disagreed: a slot the model writes by default is stated too and rides with the counts, so a dropped tail of those printed "all of them counts" while the check enforced them at FIX.
On one measured repository 49 of the 74 areas carrying the notice said something other than what the check would, 34 of them by reporting that nothing enforceable had gone
