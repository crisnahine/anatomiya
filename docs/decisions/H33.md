# H33

Section: H. Layout

## Decision

A runner group on an area's kinds line and on a root line says how many of itself sit under the directory the vote named, where that is fewer than the group

## Why

H30 fixed this on the tests line and left the sibling clause alone.
The vote needs only a strict majority, so the name can speak for as few as half the group plus one: measured across two maps, five of the ten clauses carrying a voted directory name it a count it does not hold, `11 RSpec specs under oauth` over 6, `8 RSpec specs under admin` over 5, `8 ... under users` over 5, `9 ... under oauth` over 7, and `3 vitest specs under __tests__` over 2.
The same generated file prints H30's honest pair over a 1-in-1369 gap two lines away, so a reader who has learned `N of M ... under X` as the spelling for a difference reads a bare count as the whole group.
The name is a basename by design and stays one, so `admin` still names no reachable path where the directory is `spec/services/serializers/api/v1/admin`; that is H25's question and not this one.
The count is of files whose immediate parent carries the winning name, not of a subtree, which matters where one basename is several directories
