# B53

Section: B. Engine

## Decision

Everything outside a script block is blanked in place before the parse, each block is parsed apart, and the trees are merged into one program for the file. A block with no `lang` takes the grammar a `.js` file takes

## Why

A block parsed as a slice reports offsets from the slice, and every reader past the parse would have to shift them back: the check's line numbers, a row slicing the text between two nodes, the reuse check's ranges.
Blanking keeps the string the same length in UTF-16 code units and leaves every `\n` and `\r` where it was, so each offset and each line the parser reports is the file's own.
It is the method the Flow retry already uses (B19).
Measured: on 1,632 nodes in 30 components each node's offsets sliced the file's own text to that node as written, under a BOM, CRLF endings and characters outside the basic plane above the script; and a check of a vitepress branch reported an empty catch at line 16 of a new component and at line 428 of a 949-line one, both the file's own lines.
Apart, because Vue's `<script>` and `<script setup>`, like Svelte's module and instance scripts, may import the same name, which one module may not declare twice.
Merged in file order: the program body, the comments, and the module record's four lists, with `hasModuleSyntax` true where either block has it and the program spanning the whole file.
A line comment on a script's last line runs on through the blanked end tag, so it is cut where its block ends.
`lang="ts"` takes the `ts` grammar and every other block the declared default, `tsx`, which is the route a `.js` file takes (B14): `<string>x` is legal under `ts` alone, and a block marked `tsx` holds JSX.
The tag also marks the file typed (`facets.typed`), since no extension can, and that is what admits the two rows that need type syntax.
A syntax error in either block, or a script that never closes, rejects the whole file, a block read before it included, because a recovered tree is not the file (B15).
A component with no block is an empty program, read and not rejected.
No Flow or CommonJS retry runs, since a component is built by its compiler, and `stripped` stays false.
What this gives up: an annotation in a block with no `lang` parses and marks the file typed, as it does in a `.js` file, where Vue's own compiler rejects it (`const n: number = 1` under a bare `<script setup>` reads as typed), and a block read that way is what 479 of the 545 components with a script hold in kit and 10 of 1,983 in shadcn-svelte, and none of vitepress's 68 or element-plus's 772; and a row is handed the file as written, so a doc comment on the script tag's own line is not seen as one: `<script>/** doc */` above `export function f() {}` counts `f` as undocumented, and the same comment one line down counts it documented
