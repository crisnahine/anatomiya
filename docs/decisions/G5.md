# G5

Section: G. Scope

## Decision

Success is measured by a with-map / without-map diff on real tasks, never by review-comment counts

## Why

Measured: comment data only sees what got *through* review.
Preventable comments are 8.5% of the corpus, the cheapest ones, and 93.5% of PRs are unaffected.
The pre-review effect is unmeasured, not disproven
