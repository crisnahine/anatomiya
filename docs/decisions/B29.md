# B29

Section: B. Engine

## Decision

Beaker's `test_name "..." do` macro is its own runner, `beaker`

## Why

Puppet's acceptance suite writes every scenario this way under `acceptance/tests/`; the tool recognised only the 2 of 223 files that happened to end `_test.rb`, folding the other 221 into the producer population as code owing a test it already is.
Shares the block-plus-argument gate with the Rails macro and RSpec's calls, since it is the same declarative shape; kept as its own flag rather than folded into `rspec` or `minitest`, since neither word is true of a Puppet acceptance scenario
