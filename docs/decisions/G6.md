# G6

Section: G. Scope

## Decision

The corpus takes every extension a declared language names, plus Ruby's extensionless filenames

## Why

Measured: `.mts`, `.cts`, `Rakefile`, `Gemfile`, `config.ru`, `.gemspec` and `.jbuilder` are 803 files in a 35-repository corpus, neither counted nor reported as skipped.
`.rbi` stays out: a Sorbet signature describes types rather than anything anyone wrote, so a claim counted over one speaks for no code
