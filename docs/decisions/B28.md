# B28

Section: B. Engine

## Decision

`MINITEST_SUPERCLASSES` is what a repository has been seen to inherit, twelve entries today, and an app-defined superclass one level removed from the list is deliberately left unresolved

## Why

The comment claimed "Rails ships six", which was a factual claim about Rails and was false: whitehall inherits `ActionView::TestCase` in 16 declarations and plots2 needs `ActionDispatch::SystemTestCase` and `ActionCable::Channel::TestCase`, none of the six.
Added those two plus `ActionCable::TestCase`, `ActionCable::Connection::TestCase` and `ActionMailbox::TestCase`.
The comment now says the list grows on evidence rather than defending a total, since replacing one asserted count with another invites the same mistake and a missing entry reads a minitest file as RSpec.
Declined the transitive half: plots2's remaining 22 files subclass an app-defined `ApplicationSystemTestCase`, defined once in its own file and referenced from 22 others, a cross-file relationship a per-file facet function has no index for, and resolving one level within a single file would not have fixed one of those 22, since a Rails app requires the base class rather than defines it beside every subclass

## Status

**done** `facets.mjs` (`MINITEST_SUPERCLASSES`), pinned by `test/facets.test.mjs`.
Transitive resolution across files: not built, see Why
