# B40

Section: B. Engine

## Decision

The npm argv the lock gate runs is one exported list, `LOCK_ARGV`, and a test hands npm a stub and reads back what it was handed: `--offline` under `--check`, and not for a write

## Why

B35 says a gate that reaches a registry fails on the network rather than on the repository, and nothing checked the argv carried `--offline`; a call site spelling its own argv would have passed the list.
`shipped.mjs` solved the same problem with `PACK_ARGV` and a stub npm on PATH, and the case ignores the exit status, which is the gate's own reported condition
