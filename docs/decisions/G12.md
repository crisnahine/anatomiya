# G12

Section: G. Scope

## Decision

`CONTEXT.md` is gated on shape and on one closed set, never on meaning. `check-docs.mjs` holds that every entry is whole, a definition under its name, an `_Avoid_` line closing it and no name defined twice, and that `Unexamined` names every member of `PARSE_OUTCOMES`, which the tally in `parse.mjs` now reads from that same list. It also holds every `_Avoid_` entry of two or more words, or hyphenated, that carries no sense note in parentheses, against the documents and against the comments, test names and claims of every source file, outside `CONTEXT.md` and the released changelog sections. A plural is the same word

## Why

Nothing read the glossary at all, and eleven entries had drifted by the time anyone set it beside the code.
The worst of them reached a reader: `Conforming` said "a candidate matching the positive pattern" while `facts.mjs` returns `conforming: counterSites` on a counter-stated slot, so an area file printed "5589 of 5589 sites" for a number the glossary's own word put at 0.
Meaning is not mechanically checkable, and a gate pretending to check it would be worse than none, since it would answer "the glossary matches the code" over a file whose every sentence had rotted.
Shape is checkable, and it is what a hand-edited file of forty entries actually loses.
The closed set is the one place the prose and the code hold the same list, so it is the one coupling a machine can keep.
Both halves are proved to fire by breaking a copy of the repository each way and asserting the run exits 1 naming the entry, because a gate nobody has watched fail is a gate nobody knows works.
A spelled word is checkable where it can have no other sense: `non-test` sat in a decision row and a measurement file through several review rounds, and `source file` came back in the fix for it.
Of 60 such entries, 40 appeared nowhere, and 39 still do with plurals read.
18 have another sense here (Claude Code's own rule files, a plain `left alone`) and now say in a note which sense they displace, and the two real slips, `install directory` and `spec directory`, were rewritten.
A source file is read in its comments as oxc finds them, the names passed to `test`, `it` and `describe`, and its `claim` values, templates included, so a fixture string holding the word is no finding, and a file oxc cannot parse is read whole.
No word runs across a blank line.
Given up: a single word, or a noted entry, is a reader's to judge
