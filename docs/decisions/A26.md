# A26

Section: A. Delivery

## Decision

The command word is required, and four surfaces say what the run actually did

## Why

`plugins/anatomiya/bin/anatomiya.mjs` defaulted the command to `scan`, which writes, so typing the bare name to see what the tool does replaced the map: 14 seconds and a rewritten `.claude/rules/` for somebody who only wanted to look.
A mistyped command was read as a path and refused as `not a git repository: frobnicate`, which names the wrong fix, while a mistyped option was already refused by name with the usage three lines further down.
The default was undocumented, untested and unreferenced: every call site in the repository, the plugin's own command files included, passes a command word.
The other three are the same shape, a fact the run knew and did not say.
A crash count is a `SIGKILL` off the pool's wall clock or its memory poll, so it measures the machine rather than the tree, and it moved two lines of the always-loaded overview between two scans of unchanged source, the line itself and the area listing entry it cost; it stays on the summary, which is not cached.
The type checker costs about 3x a plain scan and on a measured repository added 110 slots not one of which states, and the map, the facts store and every area file said so while the terminal the caller was watching did not.
They are not empty: those 110 hold 1,970 counted sites, `law_of_demeter` at 128 of 140 in one directory among them.
What the caller is not told is that the extra cost buys counts and no sentences.
A first pin printed 134 lines of which 127 said the same thing once per directory, because every area is new by arithmetic and the rest of the output is a fixed seven lines.
And the check computed how far the map had drifted, compared it once against the 25% cliff and threw it away, so below the cliff the reader was told nothing at all
