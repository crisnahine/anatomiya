# B73

Section: B. Engine

## Decision

The reuse check asks which of a file's lines define nothing callable through one function, `inertLinesOf`. A lexer answers for oxc and prism, and a tree adapter, loaded on the first tree-sitter file a stop reaches, parses the rest in the hook's own process, and every file a rule reads in one stop shares one second

## Why

The Stop hook runs at the end of every turn, so a stop that changed only JavaScript or Ruby loads no tree module and no grammar (A100).
The hook reaches no walker and no dimension, which `test/modules.test.mjs` holds, and `tree-sitter-file.mjs` imports both, so the runtime and its one parser per grammar live in `tree-sitter-runtime.mjs`, which imports `encode.mjs` and `langs.mjs` and nothing else of this tool's.
A scan's worker and the reuse check load the runtime through that one module.
The parse runs in the hook's process, where a parse or a walk that throws is caught and its file is asked about whole.
The budget is one second for every file a rule reads in a stop (`REUSE_PARSE_MS`): the line rules over its JavaScript and Ruby files and its component script blocks, and for its tree-sitter files the first load of the runtime and of each grammar, every parse, and every walk of a parsed tree, started at the first such file and shared by every checkout the stop reads.
A line rule costs microseconds a line and reads the clock once in 64 lines (`CLOCK_LINES`), so it meets the deadline only on a file built to be slow, and a file it does not finish asks about every line that is not blank.
The walk had no clock and was quadratic in how deep bindings nest: it searched each binding's subtree for an annotation and asked the tree for a node's parent, which the tree answers by reading down from its root.
Measured through `inertLinesOf` with a deadline one second out, on a Python file that is one line of chained assignments, `a = a = ... = f()`: 4,000 assignments, 16 KB, parsed in 10 ms and took 21.9 s under that deadline, and 8,000 took 72.9 s, at a load average of 35 to 73, past the 15 s the hook declares, where Claude Code kills it and the stop asks nothing.
Counted on that file at 2,000 assignments: 2,000 subtree searches over 6,013,000 nodes and as many parent reads before, and one search over 6,007 nodes and no parent read after, with 12,007 nodes at 4,000 and 24,007 at 8,000.
After, at a load average of 45 to 48: 33 ms at 4,000 and 70 ms at 8,000; 8,000 nested C# blocks walk in 369 ms where 4,000 took 10.1 s, and 4,000 nested Kotlin lambdas in 202 ms where they took 53.1 s.
The answers did not move with the search: the per-hunk answers over the 34,075 hunks of B68 before it and after it are byte for byte the same file.
One run stands behind the number: parse plus walk of the three largest files of each of the seven tree-sitter languages in the 25 repositories of the language corpus, 21 files of 68 to 451 KiB, each read once to warm and then timed five times, took 34 to 875 ms at the median and 1,018 ms at most at a load average of 34 to 35.
At that load the largest file ran out the budget in one read of five, and asks whole when it does.
The run B68 quotes is the one over changed files: at a load average of 33 to 51, 6 PHP files of the 21 repositories took more than a second, and each asks whole under the budget.
The hook declares 15 s and a test holds the sum under it: 2 s for the payload, two git reads of 5 s each, the second this row describes, and a second to spare.
A parse cancelled through the runtime's progress callback is resumed by the next parse on that parser: measured, the parse of `x = 1` after a cancel answered with the tree of the 5,300-byte file before it.
So a cancelled parser is reset before it is used again.
The rule reads every node type and field name from `tree-shapes.mjs`, and `test/tree-shapes.test.mjs` checks each one against the grammars the plugin ships and against a sample that holds it.
What it spells itself is token text and no node type a grammar could rename unseen: the closers `)`, `]`, `}`, `;`, `,` and `#endif`, the signs `-`, `+`, `~` and `!`, the `|` that joins types, the words `true`, `false`, `null` and `const`, an import of `"C"`, and `<script`.
The load of the runtime and of a grammar counts against the second, since the deadline is set before either, and nothing can stop a load part way: the cancel callback is first asked when `parserFor` resolves, and a file whose load outlasted the deadline is not parsed and asks about every line, a false ask and never a skip.
Given up: a file reached after the budget is spent is asked about whole, so a stop that changed many large files of the seven languages can ask about a comment.
The runtime's load and each grammar's are one promise that later callers await (`ensureRuntime`, `parserFor`, `loadParser`): a stop that read two checkouts started two loads, the second `Parser.init` under the first left a grammar unusable ("Incompatible language version 0"), and that checkout's files asked nothing, with a grammar or two of the three asked for failed in each of 4 cold runs.
Validated on the final rule: the oracle's last run over 34,075 hunks of 21 repositories named 0 hits, 26,545 asked and 7,530 left out (B75), and in a real session on the 0.15.2 build on 2026-10-13, in a copy of flask scanned by that build, a function written with the body of `get_debug_flag` drew the stop's question naming it at `src/flask/helpers.py:28`

## Status

**done** `inert.mjs` (`inertLinesOf`, `INERT_ENGINES`, `REUSE_PARSE_MS`), `inert-tree.mjs` (`treeInertLines`, `walked`, `tick`, `within`, `CLOCK_EVERY`), `tree-sitter-runtime.mjs` (`parseForLines`, `parserFor`, `ensureRuntime`), `tree-shapes.mjs` (`SHAPES`), `reuse.mjs` (`pendingChange`, `componentScript`), `hook-verbs.mjs` (`runReuse`), pinned by `test/inert.test.mjs`, `test/inert-tree.test.mjs`, `test/tree-shapes.test.mjs`, `test/modules.test.mjs` and `test/reuse.test.mjs` (`a tree-sitter file reached after the stop's parse budget is asked about whole`, `a JavaScript, Ruby or component file reached after the stop's budget is asked about whole`, `the budget starts at the first file a rule reads and is shared by every checkout of the stop`, `the git reads fit inside the time the hook asks Claude Code for`).
The walk counts each node it steps over, each node a binding check reads, and a subtree's `descendantCount` before it searches one, and reads the clock once in 4,096 counted nodes (`CLOCK_EVERY`); past the deadline it throws, and the file asks about every line that is not blank, as a file whose parse ran out does.
A file is searched once for where its annotations start, and the walk hands each node its holder and the holder around that, so it asks the tree for no parent.
`inertLinesOf` answers one entry per line, true where the line asks nothing, and null where no rule reads the file.
`inert-tree.mjs` is imported inside `inertLinesOf`, on the first file whose engine is tree-sitter.
`runReuse` hands one `parsing` object to every checkout's `pendingChange`, which sets its deadline at the first file a rule reads and hands it to `componentScript`.
`parseForLines` answers `{ tree }`, `{ rejected }` where the grammar reports an error, `{ timedOut }` where the deadline passed before or during the parse, and null where the runtime or the grammar is missing.
`treeInertLines` walks the tree with a cursor and deletes both before it answers, since a wasm tree is never collected.
A component's script blocks are read through the same function, one view per block (A91).
`test/tree-sitter-file.test.mjs` (`grammars asked for at once from a cold runtime all load: a stop that reads two checkouts starts them together`) holds the one load
