# C48

Section: C. The counted-claim model

## Decision

A stem of capitals alone is not a filename site in a file that holds JSX. It stays the SCREAMING case in every other file

## Why

React reads a capital-initial element as a component, so SBA.jsx holding `const SBA` is an acronym component.
It was a MUST-FIX against a stated PascalCase claim while sba.jsx passed, and the only name that cleared it, Sba.jsx, no longer matched the component inside.
A merged-PR replay on a real front end found this as its one MUST-FIX.
The reasons C23 and C35 give for the capitals rule, DEBUG and a GET route handler, are identifiers in module files, and there it is unchanged
