Section: H. Layout

## Decision

The common-imports line skips relative specifiers and the runtime packages a framework area cannot be written without, matched by package name so every subpath of one is runtime too

## Why

"This React area imports React" is a line the reader already has, and a sibling import is a fact about one file rather than a habit the next file should copy.
Matched on the package, so `next/link` and `react-dom/client` are the framework while a package that merely starts with the same word, `next-auth`, is not.
A closed table for the same reason C8's framework list is one, and it grows the same way
