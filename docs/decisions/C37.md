# C37

Section: C. The counted-claim model

## Decision

The check words a learned row's claim through `claimFor`, the row's owner, and holds no template rule of its own

## Why

`claimFor` carries three rules: the `noneClaim` absence, the split sentence per kind, and `encode` on a class read out of source.
The check rebuilt the second for the filename row and skipped the other two.
No behaviour changed today, because the filename row holds its learned value to `CLASSES`, so neither skipped branch was reachable from that site; C25 records this exact duplication producing a defect once, and C15 promises the second corpus row the same locality
