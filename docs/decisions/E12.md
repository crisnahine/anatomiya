# E12

Section: E. Baseline and drift

## Decision

A pinned file the base added after this branch forked is not missing: when the pin is not in HEAD's history, pinned paths absent at their merge base are left out of `missing`

## Why

With the pin following the default branch, a feature branch cut before it never held the files the base added since, and each one closed its whole area as population-change on a branch that deleted nothing.
A file the branch did hold at the fork and no longer holds is still missing, and git not answering leaves every file counted, which suppresses rather than states
