# F21

Section: F. Safety

## Decision

A binding declared inside a block is read only where that block is in reach, held over every source file by resolving each read the way the engine does

## Why

`scripts/ab.mjs` declared two bindings inside the `try` around its trials and read them after it; `node --check` passes that, nothing imported the file, and the throw came once every trial was paid for.
The guard parses every file with oxc, opens a scope per block, `for` head, `switch`, `catch`, function and named class expression, hoists `var` and the declarations the way the engine does, seeds the module with what node provides as globals, leaves `typeof` alone, and reports a read no scope in reach answers that some block in the file declares.
It went red naming the two lines before the fix, and its own driver case holds the resolution rules
