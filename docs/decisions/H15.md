# H15

Section: H. Layout

## Decision

Every spelling of a test file's name lives in `plugins/anatomiya/lib/test-shape.mjs`, and the differences between the spellings are stated beside each other

## Why

Four modules each carried their own: the roster's basename regexes, the namesake suffix list, minitest's path rule, and the runner labels, with a fifth label copy in the measure harness.
All suffix-shaped, so a new spelling meant four edits with nothing failing at three, and a prefix convention was not expressible anywhere.
The spellings deliberately differ per question, is-test against namesake against mirror-tree, and consolidating without flattening is the point: the hyphen forms count as tests and answer no namesake, which is now a stated fact with a pin rather than a scattered accident
