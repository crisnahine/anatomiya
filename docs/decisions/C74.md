# C74

Section: C. The counted-claim model

## Decision

A learned row with a closed vocabulary declares `classes`, the values its sites may vote with, and `CLASSES`, the four naming classes, sits beside `classifyWord` in `stems.mjs`; the check enforces a stored class only inside the row's list, a model default's class is held to it, and a row whose class is a name out of the source declares none

## Why

The vocabulary was spelled in four places that disagreed: the fold learned from `CLASSES` and `PREFIX_LETTERS` (`I`, `T`, `E`), the check accepted any capital or `none` for a prefix row and only the four naming classes for every other closed row, and the model defaults accepted the four plus `none` for every row.
`strong_params_style` votes with `require`, `permit` or `expect`, none of them a naming class, so the check refused every class the fold learned for it and never raised a finding on the row.
