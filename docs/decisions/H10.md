# H10

Section: H. Layout

## Decision

The section and the area `kinds` line shrink into whatever the rest of the file leaves, and both give way to a directive

## Why

A6 bounds what a reader reads, and the head, the tail and the two listings that grow are paid first.
The section gives way in this order (`fit` in `render-layout.mjs`): the sentences go first and at once, root lines get the room that is left and fold into the count that was already there, the tests line goes last, and under four lines it prints nothing, because a root line names one directory while the tests line is the denominator for all of them.
In an area file the `kinds` line prints under the heading and is dropped with the roster lines after a suppressed count and before a stated directive, since a directive is what the file exists to deliver and a description is what makes the next file fit beside the ones already there
