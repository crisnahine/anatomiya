# A42

Section: A. Delivery

## Decision

The overview carries a third fixed sentence: `When a change is asked for, follow what this repository already does and carry it through instead of stopping at a suggestion.`

## Why

A16 sends the agent to go and look; this one says what to do with what it found, which nothing in the head said.
The counts state the practice and no line told the agent to follow it.
"Follow what this repository already does" is the convention half, and its wording alone adds nothing: Claude Code 2.1.241 carries "write code that reads like the surrounding code" in one branch of its prompt block, and the map already derives sentences like "Match sibling test shape" with counts behind them.
What this half adds is delivery, not wording.
The sentence sits at the top of the file whose body is the counts, so "what this repository already does" has a denominator under it instead of being a sentiment.
Its limit: most stated directives live in the area files and the head is not in them, so what sits under this sentence is the overview's own counts, and the area files are reached by the read-before-editing line above.
Alternate 3 in the note put the pointer into the words ("prefer the practice counted below") and was rejected: it reads as documentation of this tool, and it goes half wrong the moment the interesting counts are in an area file.
So this half rests on position, and the proactive half is what the line says that nothing else in the stack says.
"Carry it through instead of stopping at a suggestion" keeps the shape of Anthropic's `default_to_action` ("implement changes rather than only suggesting them"), with "instead of" for the house idiom the line above it already uses; the Opus 5 page's "Finish the whole task, and stop short of actions that are clearly beyond what was asked" is why it is scoped instead of carrying OpenAI's persistence clause.
The trigger clause is the guard, and it is the half with a number behind it: OverEager-Gen measures this class of harness at 5.4 to 27.7% out-of-scope actions on benign tasks, and reports that stripping the consent statement "multiplies the overeager rate on every shared base model (Delta in [11.9, 17.2] pp)".
The gap it aims at is measured and large (Senior SWE-bench puts Opus 5 at 62.1% solved and 34.7% solved tastefully; NITR finds 13.3% of edits pass every functional test and fail the structural oracle; SlopCodeBench finds agent code 2.3x more verbose than 473 human Python repositories), and no study measures a rules-file line closing any of it, so no effect is claimed.
`docs/research/one-line-that-finishes-in-house-style.md` carries the sources
