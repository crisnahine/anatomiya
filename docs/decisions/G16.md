# G16

Section: G. Scope

## Decision

No fixture, comment or document carries a private repository's names, copied lines or paths: a fixture invents its names, and a measurement on a private repository describes it and renames its paths. `scripts/private-names.mjs` checks a release against the corpus, with the private repositories named on its command line and the names judged ordinary listed in a file kept beside the corpus

## Why

The corpus is 35 repositories, two of them private, and every fixture, comment and document here is public.
After every mention of the company had been renamed by eye, a match against the two private repositories' own files still found their class names, tables, services, component names and copied migration lines in 41 files: shipped code comments, test fixtures, the README, the changelog and the decision and measurement documents.
The private repositories are named on the command line and the ordinary names are kept beside the corpus because a list in this repository would name what it hides; the script refuses an accepted list that sits inside the repository it checks.
A private repository's path words count as its names, because a file it names only in its tree got past a check that read text alone, and this repository's own paths are read the same way.
A copy of the checked repository in the corpus is passed over and named, found by a shared first commit or by a tip the repository holds, which is all a shallow clone keeps, because read as public it holds every name and the check would pass on nothing; a repository with no commit is refused, since no copy of it could be told apart.
The public repositories are read in the script's own process: `git grep -F -f` over the 7,451 names this repository shares with the private ones listed 25,172 of one repository's 27,672 files and took 72 seconds before a file was read, and the whole corpus reads in 284 seconds this way.
A machine's home directory is the other way a private detail reached a public file, five research notes and two test files, so `check:docs` reads every tracked text file for it, the research and measurement notes included, and fails a document naming any home directory but the `/Users/me` placeholder, since CI runs on a runner's home and knows no contributor's
