# B68

Section: B. Engine

## Decision

The end-of-turn reuse check (A91) asks about a file of the seven tree-sitter languages as it asks about a JavaScript or a Ruby one: a hunk is left out only where every added line provably defines nothing callable and calls nothing, read off the file's tree

## Why

This row said the opposite before the tree rule: a file of Python, PHP, Go, Java, C#, Rust or Kotlin was not asked about, so a function duplicated in one of them was never searched for.
The other choice open then, asking about every added line of such a file, asked about one comment added to a `.py` file (`svc/total.py`, line 1) where the same comment in a `.js` file asks nothing.
Measured by `scripts/measure-inert.mjs` over the last 200 non-merge commits of 21 repositories of the seven languages, 9,868 changed files and 34,075 added hunks: the rule asks about 8,548 files and 26,542 hunks, and leaves out 1,320 files and 7,533 hunks.
Per language, files asked and left out, then hunks asked and left out: Python 655 and 122, 2,268 and 850; PHP 1,412 and 169, 4,946 and 1,082; Go 1,121 and 100, 2,863 and 594; Java 514 and 297, 1,351 and 2,182; Kotlin 2,003 and 410, 5,480 and 1,833; C# 1,762 and 98, 6,580 and 499; Rust 1,081 and 124, 3,054 and 493.
The oracle of that script re-parses every file holding a left-out hunk and named nothing in the 7,533: no definition, accessor, call, lambda, conditional, interpolation or declaration with no body holding a token on an added line, no string holding more than its own text, no sign a user's operator could stand behind, no literal declared as a type that could convert it, no write through a member or a subscript, and no binding holding anything but names, types and literals (B75).
No file went unread in that run and none took a second: the p99 of one file's parse and walk was 13.3 ms for Kotlin at the least and 95.0 ms for Python at the most.
What the rule asks about on purpose, and the false asks that costs, are B74.
Given up: the semantics of Java, C#, Rust and Kotlin were ruled by reading, with no compiler for them on the machine that measured; a Python `x = 1` in the body of a class whose metaclass hands back a `__prepare__` mapping that runs code is left out; and so is `var v = 1;` in C# where a type named `var` is in scope

## Status

**done** `inert.mjs` (`inertLinesOf`, `INERT_ENGINES`), `inert-tree.mjs` (`treeInertLines`, `inertBinding`, `inertDeclaration`), `tree-shapes.mjs` (`SHAPES`), `tree-sitter-runtime.mjs` (`parseForLines`), `reuse.mjs` (`pendingChange`), pinned by `test/inert.test.mjs`, `test/inert-tree.test.mjs` and `test/reuse.test.mjs` (`a tree-sitter file is asked about the hunks that may define something, and only those`).
A line asks unless it is blank, or everything on it is a closing bracket, a `;`, a `,`, a C# `#endif`, or part of one of the nodes below.
Python: a comment, an import, a docstring, and an assignment of a literal to a name or to a pattern of names, with an annotation made of names.
PHP: a comment, a `use`, the tags and the markup around the code, a constant or a declared property with a literal default beside its modifiers and its type, and an assignment of a literal to a variable or to a pattern of variables that is a statement of its own.
Go: a comment, an import, the package line, and a `const` or a `var` bound to a literal or to a composite literal of literals, and a `const` of a group with no value or counted off `iota` with literals and operators.
Java: a comment, an import, the package line, and a field or a local bound to a literal.
C#: a comment, a `using`, `#endregion`, and a field or a local bound to a literal under a predefined type, under `var`, as a `const`, or to `null`.
Rust: a comment, a `use`, and a `const`, a `static` or a `let` bound to a literal, with a type and a pattern made of names.
Kotlin: a comment, an import, the package line, and a property with no accessor bound to a literal.
A literal is a number, a character, a string that interpolates nothing, `true`, `false`, the language's null, or a collection holding only literals.
A line longer than 400 characters asks unread, as it does under the line rules of A91.
A file the grammar rejects, one whose parse ran past the stop's budget and one the runtime failed on ask about every line that is not blank (B73).
A file whose grammar or runtime is missing is not asked about, since nothing read it
