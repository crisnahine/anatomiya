# B68

Section: B. Engine

## Decision

The end-of-turn reuse check (A91) asks nothing about a file of the seven tree-sitter languages

## Why

The check asks about an added hunk unless every line of it is blank, a comment, an import, a name bound to a literal or a closing bracket, and it tells those apart with a line rule per engine.
`INERT` holds a rule for oxc and for prism and none for tree-sitter, so with no rule every added line of such a file counts as defining code.
Measured with those files asked that way: one comment added to a `.py` file is asked about (`svc/total.py`, line 1), where the same comment in a `.js` file asks nothing.
With them left out, a function added to a `.py` file asks nothing and the same function in a `.js` file is asked about.
Given up: a function duplicated in one of the seven is not asked about, until a language has a line rule of its own
