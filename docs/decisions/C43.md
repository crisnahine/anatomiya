# C43

Section: C. The counted-claim model

## Decision

A capability row's site is the operation its sentence names: a logger site is an output call, and a class under an HTTP library's namespace is a site unless it is that library's error, exception or cookie jar. `zone_aware_time` says times are read and built, since it counts `Time.parse` and `Time.zone.at` on purpose

## Why

On rails-api `config` printed a logger row off three `config.logger.level =` lines, and setter-only files counted toward the three adopters C14 asks for; `spec/services/models` printed an HTTP row off one `HTTParty::Error.new`.
The time sentence named the clock while its sites were parses of a value.
Over-counting a direct HTTP site stays the safe side, so only the measured helpers are excluded
