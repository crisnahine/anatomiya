# F3

Section: F. Safety

## Decision

One encoder, allowlist not denylist: reject non-printable codepoints, NFKC normalise, reject a word mixing look-alike scripts, reject `|`, `---`, comment delimiters, backtick runs; cap **before** quoting, on grapheme clusters; emit paths JSON-quoted

## Why

Bidi controls and zero-width joiners are category Cf and pass an ASCII control filter; `JSON.stringify` does not escape them either

## Status

**done**.
The cap and the mixed-script rule are display rules for text a file loads; the check report's paths do not take them (F4).
Revised: the rule is per word, a run of letters between separators, dots and digits, and only across the alphabets whose letters share shapes (Latin, Cyrillic, Greek).
`src/раyments.ts` is still refused; `приложение/компоненты/форма.ts`, `src/工具/格式.ts` and `λ/συνάρτηση.js` are names in their authors' own language and are rendered as written.
Refusing every non-Latin path left a repository written in Russian or Japanese with no area at all and an overview of placeholders (`test/encode.test.mjs`).
Armenian and Cherokee joined the look-alike set: `օ` is a Latin `o` and `Ꭺ` a Latin `A`, so `src/cօnfig.ts` and `src/Ꭺdmin.ts` are refused, while a name wholly in either is kept.
Revised again for what renders as nothing: variation selectors, the combining grapheme joiner and the Hangul fillers are marks and letters, not Cf, so the allowlist kept them and a payload rode inside one grapheme.
Every default-ignorable code point is removed now, the Cf ones still to a space.
And the cap bounds length, not only count: one grapheme holds any number of marks, and `encode("x" + U+E0101 × 500,000, { max: 5 })` came back as 1,000,001 code units.
A grapheme keeps eight code points, a base and seven more, which is the longest conjunct a script writes, and a value four code units per grapheme of its cap A number at the head of a value is a list marker only before a space or at the end of the value, so `13.x`, `404.vue` and `3.2/app` print whole and `1. release` prints `release` (`encode.mjs`, `BLOCK_MARKER`).
Release 0.13.4 took any number and dot at the head for a marker: it printed `x` for `13.x`, `vue` for `404.vue` and `2/app` for `3.2/app`, and a directory spelled that way got no area file.
Measured on 13,524 names, 23 heads of digits and a marker by 42 characters after them (every Unicode space, format character, filler and entity spelling among them) by 7 tails, through `encode` and `sanitisePath`, alone, before a caller's text and inside a root line: none opens a CommonMark or GFM list or block.
Given up: a directory named as a number, a dot and a space (`1. x/src`) prints as what follows (`x/src`), and one named only `1.` prints `(unnamed)`
