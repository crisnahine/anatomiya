# A39

Section: A. Delivery

## Decision

One tag namespace per plugin, resolved by a module the release workflow runs rather than by shell inside it. Each plugin carries its own version, its own changelog and its own coverage floor

## Why

One tag namespace and one changelog served every plugin the marketplace listed, and the dangerous shape was not a tag that failed: a bare `v0.1.0` matched a second plugin's version, found no section of its own, and would have released anatomiya's `0.1.0` notes under that plugin's name, silently.
The logic moved out of the workflow because a release cannot be taken back and six lines of `awk` inside a YAML file cannot be run until a tag is already pushed.
The same module is what `check-docs` now calls, so a version that passes on a branch is a version that will tag.
The coverage floor was one number over the whole tree, and what an aggregate hides is proportional to how much larger the rest of the scope is: a file can sit under every floor with the total never showing it.
A scope is held to a floor per file now, read off an lcov record rather than off the total node prints.
A round aimed at that fix measured the same silence one scope up: 33 of 149 files sat under the whole-tree floor on their own with the total clearing 95, and `check.mjs` could have lost every covered line unnoticed.
`lib/` is held to a floor per file too, with `dimensions-semantic.mjs` named as an exception rather than the floor lowered to admit it, and a stale exception reported as its own problem.
The floor caught `tsconfig.mjs` at 71.4% of functions on the first run it was enforced, and the cause was that every case in `test/tsconfig.test.mjs` sits behind `needsTs`: the file has tested the confinement since 0.1.11 and skips wherever TypeScript is absent.
Eleven cases were added beside them that hand the two host builders the module they already take as an argument, so the confinement is measured on every runner.
The rest of the tree stays on an aggregate because the type-checked tier and the by-hand measurement harnesses are deliberately uncovered by the unit suite.
`docs/releasing.md` said a guard held a hook to a file it ships, and deleting a plugin's whole declaration passed every gate, because the hook check returns without a word when the file it was going to read is not there
