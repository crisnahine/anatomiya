# G24

Section: G. Scope

## Decision

The website is the static files under `site/`, filled in by `scripts/site.mjs` from the repository it describes and deployed to GitHub Pages from `main` by `.github/workflows/pages.yml`: its examples, results chart and counts are read from the README, the usage guide, the registry, DECISIONS.md and the code index, and its find demo runs the plugin's own `find.mjs`, copied byte for byte, over the index a scan of the deployed commit wrote

## Why

A page that restates the README drifts from it the first time a number moves, and the README is the copy the docs gate holds. Filling the examples, the chart and the counts at build time leaves one copy of each: a placeholder the build cannot fill, a heading the page quotes that the README lost, or reuse tables it can no longer read stops the build rather than shipping braces or a stale count. The rest of the page is prose, and a test holds every number it types to one the README or the usage guide states, and each line of Plate 1 to the usage guide's area file.
The find demo is the ranking code itself rather than a recording of it. The shipped-set walk names the four modules it loads and the one specifier none of them answers, `node:path`, which `paths.mjs` imports for a function the demo never calls; the page's import map points it at a stand-in that throws if it ever is called. Tests hold the import map to that walk and the four modules to no Node global, and the demo was run in Chrome on 2026-10-30.
Plain HTML, CSS and two module scripts, with no framework, no build tool beyond that script, and no script or style from another origin: a static-site generator would add a dependency and a build for one page. The job that installs and scans holds `contents: read`. The deploy job holds `pages: write` and `id-token: write`, runs nothing but the deploy action, and runs only on `main`, by the workflow's own condition as well as by the `github-pages` environment's rule, the split the release workflow already makes (G23).
