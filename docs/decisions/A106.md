# A106

Section: A. Delivery

## Decision

The limits of the Cursor and Copilot copies are stated: delivery is measured in neither tool, the hooks do not run there, a VS Code user is offered each area twice, and Codex gets nothing

## Why

A1 rests on a measurement that its channel reaches the model and its subagents, and nothing like it exists for these two.
Cursor: the client code of 3.20.21 hands a rule with `globs` to the agent with the result of its first read of a matching file, and not on an edit or a write of a file it never read.
That is read from the shipped code and was not seen in a running Cursor, and what Cursor's servers do to the prompt is not visible from the client.
Copilot: its delivery was not observed in any running Copilot, and the machine this was measured on holds no Copilot CLI and no Cursor command line.
The parser and the matcher of VS Code 1.140.0 with Copilot Chat 0.68.0 were lifted and run on generated files (A103).
The cloud agent, code review, the CLI, Visual Studio, JetBrains and Xcode were not read.
GitHub's own support table lists path-specific instructions on GitHub.com for the cloud agent and code review and not for chat.
VS Code already reads `.claude/rules/*.md` and turns `paths:` into the same pattern string, so with the Copilot target on its agent is offered each area twice, and in the `.claude/rules` copy it reads a `!` entry as a pattern that matches nothing.
The Copilot target is for the surfaces that read only `.github/instructions`.
The hooks are Claude Code's: the echo (A24), the pre-write notice (A44), the end-of-turn reuse check (A91) and the refresh (A95) are declared by a Claude Code plugin, so a Cursor or Copilot reader gets the map's files and none of the four, and those copies move only when a Claude Code session's refresh or a scan by hand rewrites them.
Codex is left out: it reads one `AGENTS.md` per directory from the git root down to the working directory, with no path scoping and 32 KiB for all of them together.
An area file has nowhere to go there, and the overview would be a marked block inside a hand-written file, which is the write A1 exists to avoid.
`docs/research/what-cursor-and-copilot-read.md` carries the sources for this row and for A102 to A105
