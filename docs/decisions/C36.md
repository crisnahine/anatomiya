# C36

Section: C. The counted-claim model

## Decision

The Ruby hit's `node` and a call's argument list are built by `site` and `args` in `ruby-walk.mjs`, and both registries import them

## Why

`site` existed byte for byte in `dimensions-ruby.mjs` and `dimensions-rails.mjs`, and only one copy carried the B5 reason its offsets are null; the argument read was spelled inline four times in two forms in one file and through `args` six times in the other.
C11 is the identical move already made for `value`

## Status

**done** `ruby-walk.mjs` exports both, the registries import them, and `test/ruby.test.mjs` pins the shapes and reads that neither registry spells its own
