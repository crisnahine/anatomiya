# H53

Section: H. Layout

## Decision

Past its name, a file the parse read is a test by its address, a `__tests__` segment or the mirror of a source path from a test tree, only where it exports nothing, and a Ruby file only where its parse found a case. A file the parse could not read, or whose facets it could not finish (`unread`), keeps the path rule

## Why

Measured on both corpora, 60 repositories (`docs/measurements/2026-10-11-test-by-address.md`): the two address claims took 645 files in 14.
The 328 that export are fixtures, helpers, mocks, drivers and configs, every one (canvas-lms 114, react 180, vitepress 17), and the 11 Ruby files with no case are page objects, factories and support helpers.
The 306 kept are eslint's 294 mirrored rule tests, one react test that exports nothing, and 11 declaration and setup files the rule does not reach.
Three namesake counts were false credits and fall: vitepress `docs` 3 of 10 to 0 and `template` 2 of 2 to 0, whitehall `features` 2 of 96 to 0.
None of the 328 declares a case through a call shape the case list lacks, and no file the tool reads inherits `Test::Unit::TestCase` or a MiniTest base (`docs/measurements/2026-10-11-test-shapes-outside-the-lists.md`).
The Ruby half is read off the declaration (`importGraph` false), not a language id, for B21

## Status

**done** `layout.mjs` (`isTestFile`), `ruby.mjs` (`unread` on the fallback facets), pinned by `test/layout.test.mjs` and `test/ruby.test.mjs`.
A test name still wins whatever the file exports, and a file nobody parsed is read by its path.
Given up: a test that exports a helper and has no test name, no runner import and no top-level case reads as support, none in 60 repositories; a Deno or test-unit repository outside the corpus is misread; the 11 declaration and setup files stay tests, so vitepress `__tests__` reads 56 where 53 is closer
