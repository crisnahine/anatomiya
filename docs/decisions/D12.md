# D12

Section: D. Gates

## Decision

Where files tie for the most sites, the leave-one-out drops the tied file worst for the side being judged: the one with the most conforming sites for the claim, and the one with the most counter sites for the counter

## Why

Taking whichever tied file sorted first made the verdict depend on a filename.
Ten one-site files with one violator read 9 of 9 when the violator sorted first and 8 of 9 otherwise, so a rename-only commit stated a withheld claim with every count unchanged.
On empire-flippers/api three withheld rows sat on that edge (app/services/api/v1/users, app/services/shopify/fetch, spec/services/hubspot).
Skipping the leave-one-out when every file ties was refused: it loosens the bar that most orderings already applied, and it does not cover a partial tie
