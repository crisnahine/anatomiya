# C72

Section: C. The counted-claim model

## Decision

A question several engines ask stays one row per engine, under its own key: one key is one predicate (C14, C59, C62), and no existing map, baseline, pin, model default or counter pin changes. `SIBLINGS` in `test/registry.test.mjs` lists each such set and holds every language to one row per question, every set to learned rows or to fixed ones alike, and each sibling's claim and counter-claim to the sentence written down there, so a sentence edited alone or a counter-claim given to one sibling fails until the set's record says why

## Why

Seven questions are asked by 18 keys: whether a handler uses the error it caught, which case URL path segments take, which class a class inherits, whether output goes through a logger, whether network calls go through the repository's client, whether a function declares what it returns, and whether a public function carries a doc comment.
One key per question would rekey every model default and counter pin, and every map: the check finds a slot by its key, and a site's identity includes the key, so every baseline and pin written before would read as drifted.
Each key's precision and counter-claim were settled on its own engine and differ within a set: `explicit_return_type` is partial and `declared_return_type` precise, and a counter-claim ships only where it was measured (C6).
The three differences the architecture review named as drift are each a decision rather than drift, so this records them instead of changing them: JavaScript writes `extends` and the other languages inherit; Python and PHP mark no export, so `declared_return_type` asks every named function (C53); and `explicit_return_type`'s other side is refused as a defect (`REFUSED` in `test/fixtures/counter-pins.mjs`), where `declared_return_type`'s cleared the bar on django and laravel (C53).
What could drift unnoticed is a new row asking a language a question a sibling already asks, which states two sentences for one question in one area, or a sibling's sentence edited alone; the test refuses both, for a row someone has listed in the set.
