# C47

Section: C. The counted-claim model

## Decision

A returned object is a result when it carries an ok discriminant, or an error or success key with no key a result is not made of (error, success, data, value, result, valid, isValid). What getDerivedStateFromError returns is React state

## Why

A hundred view-model hooks returning { label, error, disabled } stated 'failure is returned, not thrown' at 101 of 103 over two real throws, and the check flagged the next throw.
On the client map, 2 of the 6 conforming sites were a form hook and an ErrorBoundary.
Requiring ok alone was measured and refused: it took supabase from 136 conforming sites to 24, dropping its { data, error } mutations and { success, error } operations, which do return a failure as a value.
The key rule keeps 91
