## Decision

What a branch changed, the committed diff from the fork point, the work still pending in the tree and the lines each file gained, is one module that the check and the Stop hook both read

## Why

`reuse.mjs` took `addedRanges` and `pendingPaths` from `check.mjs`, so it reached 48 modules, the parser and every dimension among them, for two git reads.
The same code, pending edits, renames and deletions, is the part of the check that changes most, and it had no test of its own: every case ran a whole check
