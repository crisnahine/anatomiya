# H21

Section: H. Layout

## Decision

`rootFacts` matches a root's producers against whichever of the two printed extensions is a language this tool parses, not always the first by count

## Why

The denominator has to be a number the line already printed, which is true of either shown extension and not only the larger: a marketing site's own screenshots outnumber its components, and matching only the most common extension read every producer there as zero rather than naming the real ones.
Coupled to `apps` joining the shell names in H3: breaking supabase's `apps/www` (`.png` at 2,179 against `.tsx` at 753) and `apps/docs` (dominated by `.mdx`) out from behind the old blended bullet would, without this, have made their roster lines report zero producers instead of the truth, which is worse than the blend they replaced.
Fixed together, so a newly visible site is honest rather than silent
