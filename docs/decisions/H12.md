# H12

Section: H. Layout

## Decision

Whether a learned class may be enforced is asked of the row, not of the four naming classes

## Why

C13's check compared the stored class against the closed list of naming classes, which is the whole vocabulary of the rows that existed then.
A superclass name and a prefix letter are neither, so all five new rows would have stated a sentence in the map and enforced nothing on the branch, silently, which is the one asymmetry between the two surfaces this design cannot have.
`enforceableClass` asks per row: a source-learned class holds when the encoder leaves something of it, a prefix row's vocabulary is one capital letter or `none`, and everything else still votes for one of the four
