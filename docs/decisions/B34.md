# B34

Section: B. Engine

## Decision

A row may declare `needsTypeSyntax`, and all three readers drop it for a file that cannot carry a type annotation: the parse does not run it, the fold leaves the file out of its denominator, and the check does not enforce it

## Why

`explicit_return_type`'s own `blind` field already said a plain JavaScript file has no annotation to find, and the row counted those files anyway: `export function total(rows): number` is a SyntaxError under Node, so every site in a `.js` file was a violation nobody could act on.
The extension is the fact and it belongs in `plugins/anatomiya/lib/langs.mjs` beside `dialect` and `commonjs` rather than in the row, because `.js` and `.ts` share one language id here and nothing downstream can tell them apart.
Dropped at the selection seam rather than inside `run`, exactly as `blindWhenStripped` is: bailing inside `run` would leave the file in `langFileCount`, so the applicability gate would read the predicate as narrow on a mixed directory, which is the failure C3 and C4 exist to stop

## Status
