# A94

Section: A. Delivery

## Decision

A script reads its command line through one strict reader, and the corpus selection and the `--md` overwrite rule the corpus scripts share sit beside it

## Why

Six scripts walked argv by hand and each refused a different subset: one read a missing value as the next flag, two took a second positional over the first without a word, and `release.mjs` had grown its own refusal of a dash-led value after a typo wrote the notes to a file named `--notes-file`.
`util.parseArgs` in strict mode refuses an unknown flag, a missing value and a value that starts with a dash unless it is written `--flag=-x`, on every node the engines range admits; what it does not refuse, a flag given twice and an empty path, `release.mjs` still refuses itself.
Tests match the error code, or the flag on the first line of stderr, never node's wording, which is not an API.
The plugin's own CLI keeps its loop: most of it is the per-verb refusals, which stay either way
