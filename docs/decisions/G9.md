# G9

Section: G. Scope

## Decision

The `build` exclusion does not fire when the segment is reached by descending through `src`

## Why

turbopack-cli's `src/build/mod.rs` is a hand-written Rust module named for the verb, not compiled output, and the bare-word match dropped it with no repository where Rust is read to notice the loss.
A repository's own `src/` is where its hand-written source lives by construction, and no bundler writes its output one directory inside it

## Status

**done** `corpus.mjs` (`isBuildOutput`), pinned by `test/corpus.test.mjs`.
Whole-segment match only, as before: `rebuild` and `build-tools` still do not fire.
Output at a package root or one directory into a monorepo package is unaffected, since neither sits under `src`.
Not extended to `lib`, `app`, `packages` or `source`: only `src/build` was measured, and reaching further risks the overreach G8 was written to avoid
