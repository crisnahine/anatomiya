# H9

Section: H. Layout

## Decision

The reuse line resolves a specifier on the path tail, an ambiguous tail resolving to nothing, and counts only importers outside the area

## Why

`~/utils/user` and `@/utils/user` both name `src/utils/user.ts` because the tail `utils/user` does, which is the shape C9 already learns a companion root with; a tail two files answer resolves to neither, or one file is credited with another's readers.
No `tsconfig` is read, because the aliases a repository points at its own root with are a short closed list and a wrong resolution here is a wrong number rather than a missing one.
Counting the area's own files made this repository's `lib` line report twelve readers of a name eleven of its own modules pull in: a directory importing itself is how it is written, not who depends on it

A namespace import names no export and is not a row: it printed as an empty name, `most imported from here:  (5 files)`.
A default import, or a `require` bound whole, is `default` on every module, so its row is named for the module, `u1 (default)`, and an index file for its directory (`rowName`).
