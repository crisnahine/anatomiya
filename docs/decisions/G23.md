# G23

Section: G. Scope

## Decision

A release carries the plugin's directory as the tagged commit holds it, `<plugin>-<version>.tgz` out of `git archive` with its lockfile, beside its SHA-256 and SLSA provenance the release workflow signs through Sigstore with its own identity, written as the Sigstore bundle and as an in-toto provenance file, so `gh attestation verify <tarball> --repo crisnahine/anatomiya` answers which workflow at which commit built it

## Why

A release held the changelog section and nothing else, so nothing a person could download said which commit or which workflow produced the plugin they installed by hand, and the OpenSSF Scorecard read the repository as having no release to check: its Signed-Releases check ignores a release that carries only GitHub's source archives.
The archive is the plugin's directory as the tag holds it, which is what `/plugin install` copies, lockfile included. `npm pack` was the first build, and a review found it one file short: npm never packs a `package-lock.json`, and the lockfile beside the manifest is what Claude Code installs the plugin's dependencies from, so a copy installed by hand from a packed tarball would resolve its ranges to versions nobody tested. Checked on 0.22.0, the archive holds the same files as the tracked directory; the release job refuses an archive with no lockfile, and it still installs nothing and runs no test.
The provenance comes from GitHub's own attestation action, pinned by commit like every other step, rather than the SLSA generator's reusable workflow, which has to be referenced by tag and would cost the pinned-dependency gate. Its DSSE envelope written out alone is the `.intoto.jsonl` shape the Scorecard and the slsa.dev tooling look for, and the bundle beside it is what `gh attestation verify` and `cosign` read.
`/plugin install` copies the plugin directory from the repository and never downloads the tarball, so the attestation says what the tagged commit shipped and lets a copy taken by hand be held to the tag; it says nothing about the code in it.
