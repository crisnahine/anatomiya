# H59

Section: H. Layout

## Decision

A JavaScript import of a package this repository's own workspace declares resolves through that package's directory, by the name its `package.json` gives, and a name taken from a file that only hands it on (`export * from`, `export { a as b } from`) is credited to the file that defines it

## Why

excalidraw's 385 files that import `@excalidraw/common` resolved to nothing, so `packages/common/src`, where its helpers live, had no reuse line; the specifier names a package, not a path, and its index re-exports every helper from the file that defines it.
After the change the line names `KEYS (101 files)` and `arrayToMap (63)` there, and `pointFrom (93)` in `packages/math`.
A package is only a manifest the workspace's own globs reach: the root manifest's `workspaces`, `pnpm-workspace.yaml` (a block or a flow list, with Windows line ends or not), `lerna.json`, and the `projectFolder` of each project `rush.json` lists, read as JSON with comments and trailing commas; a fixture under `test/fixtures/react` named `react` took every `import React` before this was held, and a repository with no workspace has no other package. A glob may start with `./` and end with `/`, and `**` stands for no directory as well as for many.
An import of the package's bare name tries the entry its manifest gives (`source`, `module`, `main`, `exports["."]`), which is how a package whose code sits under `lib/` is found, then a `src/index` and an `index`.
A name two manifests give names neither, as an ambiguous tail does (H9), and a manifest that is no JSON names nothing.
A chain of barrels is followed until a file defines the name; a chain that runs back on itself, or ends where nothing defines it, leaves the name with the file the importer named. Each barrel's `export *` lines are read once into a table of which file hands on which name, since asking each name of every file a barrel lists took 4.6 s for a barrel of 2,000 modules and 10,000 imported names, and 92 ms with the table.
No `tsconfig` is read for this (H9): the manifest's name is the package's own, and a `paths` entry is a second spelling of it
