# A114

Section: A. Delivery

## Decision

A directory name the map prints is quoted as JSON where its encoded form holds a space or a `"`, and printed bare otherwise. One function, `nameText`, decides it for every line that names a directory: root lines, `under` clauses, the tests line, the scan's layout line, an area's heading, the Areas listing, the lines of a Cursor or Copilot area file that name patterns its file matches or cannot be given, the notice and a `check` reason. A co-change line quotes every directory and file it names, through `encodePath`, as this tool's messages quote a path

## Why

A name that is a sentence arrived as a sentence at the start of a bullet in a file that loads every turn, three such files with `--targets cursor,copilot`.
Quoting every name would change every overview once; quoting none leaves the sentence.
The set was measured (`docs/measurements/2026-10-11-quoted-directory-names.md`): across both corpora 113 tracked directory names hold a space and all read as words, none of them reaching a map, so no corpus map moves; a set of letters, numbers and `._/-` also quoted 18 map lines in 3 repositories (`@prisma`, `@modal`, `$ref`) that are ordinary paths.
The quote is in the set because a bare name that starts with `"` reads as a quoted one, to an agent and to `pathOfRootLabel`
