# D16

Section: D. Gates

## Decision

A site may carry the section it belongs to, the declaration it sits in. Where a slot's sites do, `concentration` counts sections in place of files and leaves out the largest section, `applicability` holds the count of sections to the floor a count of files is held to, and `directories` counts each section as a directory of its own. A route's section is its own declaration, the route object, element or server call in JavaScript and the route call in Rails, never a route, a namespace or a scope around it. In such a slot a file holding any conforming site is no exception to it

## Why

A route table is one file by design, so read by file every route row is one file's habit, and three gates refused it before its counts were asked: a measured React front end's `src/router` holds its 41 sites in 1 of 8 files, and a measured Rails API's 259 sit in one.
Borrowing (D8) answers only the evidence gate, and an exemption from concentration alone left applicability and directories standing.
Each route in a table was declared on its own, often by a different change, so its declarations are the independent places the evidence comes from; the authors gate still asks who wrote the file.
A section first spelled the path's first word, and a measured Rails API, which wraps every route in `namespace 'api'` and `namespace 'v1'`, read as one section and stayed refused at 269 of 273, a count taken before C59 left out single words and cut-off words; a namespace is a prefix every route under it shares, the way a directory is.
A section was then the outermost route around a site, and a React Router table nested under one layout route, `{ path: "/", children: [...] }`, read as one section: a synthetic table of 44 sites stated flat and was refused wrapped.
The printed `across N of M files` stays a count of files, because that is the denominator a reader audits.
An exception is still named by file, and a route table holding the claim's own routes was named the exception to it, `except "config/routes.rb" (3 sites)` on a measured Rails API, which tells an agent the one file the claim was counted over is exempt; so only a file whose every site breaks the claim is named
