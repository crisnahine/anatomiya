# C62

Section: C. The counted-claim model

## Decision

`endpoint_segment_case` learns the words of the URL paths routes declare in Python, Java, C# and Rust, with the site rule of C59 and the section rule of D16. A path not written as one whole string is the blind spot. PHP, Go and Kotlin were measured and are not asked

## Why

The seven tree-sitter languages declare routes too, and #239 asked whether their path words hold a repository's own spelling.
A third key rather than a wider C59 row, because one key is one predicate on one engine, and this one reads a tree-sitter tree.
Measured on clones of 16 repositories with the row (`docs/measurements/2026-10-23-unread-classes.md`), the class a repository holds differs inside each language, which is how a row that learns its class clears the bar's spread (C67): Python netbox kebab-case in 10 areas (`netbox/dcim` 99 of 99) against healthchecks snake_case (`hc/front` 7 of 7); Java thingsboard camelCase (`controller` 416 of 430) and mall camelCase (53 of 53 and 26 of 26) against dolphinscheduler kebab-case (104 of 114, stopped at the evidence gate); C# bitwarden kebab-case in 7 areas against jellyfin PascalCase (`Jellyfin.Api/Controllers` 139 of 139); Rust vaultwarden kebab-case (`src/api/core` 70 of 72) against lemmy snake_case (`crates/api` 28 of 28, stopped at the evidence gate).
Read by the bar's letter Python, C# and Rust hold no repository with 20 sites under 0.90, and appsmith's Java `controllers/ce` is the mixed one (27 of 43 kebab-case, refused at the ratio gate).
The row reads the research probe's own sites exactly in 10 of the first 12, bitwarden 239 of 241 (the 2 it misses sit in doc-comment examples) and nopCommerce 0 of 14, all of them `MapControllerRoute(pattern: ...)` conventional routes, a form left out.
Every exception in a stated or near slot was read word by word and each is a route path the team spelled; `swagger-ui` in thingsboard is a third-party UI's own name.
PHP: every Laravel route file sits in `routes/`, 2 or 3 files under the area floor, so 365 sites in 4 repositories land in no area and no claim can state.
Go: one repository has 20 or more sites, gitea, mixed at 0.545 snake_case, and the gin and chi apps write single words (photoprism 0 sites in 183 declarations).
Kotlin: no application reaches 20 sites (ktor-samples 16), ktor's 34 include 22 in a test fixture tree, and 60 of 368 literal paths (16.3%) sit in files the Kotlin grammar rejects

## Status

**done** `dimensions-tree.mjs` (`endpoint_segment_case`, `ROUTE_FORMS`, `TEST_ITEMS`, `pathValues`, `wholeString`), `tree-shapes.mjs` (`route`, `routeArgs`, `argument`, `array`, `string`, `stringText`, `quote`), `stems.mjs` (`addPathSites`, `namesWellKnown`, and `walkPath`, which skips a `<x>` segment as a parameter), pinned by `test/dimensions-tree.test.mjs`, `test/applicability.test.mjs`, `test/check.test.mjs`, `test/naming.test.mjs` and `test/fuzz.test.mjs`, and listed in `test/fixtures/counter-pins.mjs`.
The forms read: a Python route decorator, by its first argument, `path=` or `rule=`, and `add_url_rule`, on a path starting with `/`; Django's `path`, by its first argument or `route=`, in a file importing django.urls; the `prefix=` and `url_prefix=` of a router or blueprint; Spring's verb mappings and `@RequestMapping`, except in an interface marked `@FeignClient`, in any order of its annotations, whose mappings name another service's routes; ASP.NET's `[Route]` and verb attributes and the minimal API's `MapX` calls, a generic one by its method's name; actix's and rocket's verb attributes and `.route`, `.nest`, `.mount`, `resource` and `scope`, on a path starting with `/`.
A route in or on an item marked `#[cfg(test)]`, a module or the handler itself in either order of its attributes, holds no site, as a test file's routes do.
A route's section is its declaration's argument list, keyed on its offset, since a chained call starts where the whole chain does; a site's identity is its string literal, so a route that moves down the file is no new finding.
A path under `.well-known` makes everything under it no site, carried by a Java or C# class mapping or by a call's own arguments; a FastAPI or Flask prefix and a chained `MapGroup` do not carry it.
The C# forms and Django's `path` ask no leading slash, since `MapGet("todos")` is valid there; the Python decorators, `add_url_rule`, the prefixes and every Rust form do.
Not read: Django's `re_path` and `url`, which take a regular expression; Starlette's `Route`, `Mount` and `WebSocketRoute`, which no application in the corpus calls; `MapControllerRoute` and `MapRoute` conventional routes; an interpolated string (a Python f-string with a field), a C# verbatim or raw string, a Rust raw string and a string with an escape, a Java text block and Python's implicit concatenation, which are no single string node; `nest_service`, flask_restx's `add_namespace`, JAX-RS `@Path`, Ktor and gin; a request client's `.get("/x")` outside a decorator.
A per-area facts diff over the 35-repository corpus against 0.15.6 moves no slot of any other row through this one: the row opens 2 slots, both in appsmith's Java server (`controllers/ce` 27 of 43 kebab-case, refused at the ratio, and `git` 12 of 12, refused at evidence), and states neither. A `re_path` or `url` regex is rare where it is read at all: 2 of 1,610 literal Python paths the probe read hold an anchor or a named group, both in django's own admin docs
