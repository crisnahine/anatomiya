# B12

Section: B. Engine

## Decision

The baseline reads only files that differ from the pinned commit; the rest reuse the corpus parse

## Why

Measured: the baseline stage was 6,875ms of an 8,768ms scan, re-reading through one `git cat-file` process per file, as a blob was read then, on a repository where nothing had changed.
90ms with only the changed files read.
A changed file's blob is read through one child per call since (E17), so a read costs less than that measurement paid, and a file left unread is still a file not parsed twice
