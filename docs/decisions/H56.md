# H56

Section: H. Layout

## Decision

Seven kinds of test spelled as their own dotted segment name a test file: `.unittest.`, `.basictest.`, `.longtest.`, `.spectest.`, `.stest.`, `.integrationTest.`, `.releaseTest.`, cased as written

## Why

vscode's 104 tests by these names call `suite`, `ssuite` or `flakySuite`, which no case list reads, so they were no tests at all, and 4 of webpack's call only `describeCases`.
Of 235 tracked names across 60 repositories with a dotted segment ending in `test` that the name rule missed, these seven take 226 real tests and none of the 9 others, one of which, element-plus's `.vitest.tsx`, is a test its runner import already names (`docs/measurements/2026-10-11-dotted-test-kinds.md`).
A wider `[a-z]+test` takes `eslint.config.vitest.js`, and the camel form is held to the two words measured, since `a.baseTest.ts` would read a helper as a test.
The name branch sits above the export clause (H53), so a test that also exports a fixture stays a test
