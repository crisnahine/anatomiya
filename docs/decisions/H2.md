# H2

Section: H. Layout

## Decision

No vocabulary of kinds. A line is labelled with a directory name and a count is nouned with an extension

## Why

"components", "services" and "helpers" are a taxonomy this tool would have to ship and then defend on every repository, and the repository has already written the name it uses on the directory itself.
So the tests line reads `0 of 504 .tsx files have a namesake test` rather than `504 components`, and a root prints as the path it is.
It also removes the whole class of failure where a repository's own word for something disagrees with ours
