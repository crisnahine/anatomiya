# A23

Section: A. Delivery

## Decision

An area's kinds line is tried on the same floor a stated directive already gets, rather than gated behind a check on the room the `paths` list left

## Why

`MAX_LINES - head.length >= MIN_BODY_LINES` decided whether the kinds line was attempted at all, so an area carved into enough children to fill its `paths` list with exclusion globs lost its kinds line before a single directive competed for the body's own guaranteed floor.
Measured on cal.diy: `packages/app-store` (250 files, 38 exclusion lines) and `packages/features` (117, 34) printed no kinds line and no roster line, though the data existed and was already counted in the summary.
The kinds line is the one sentence a reader wants before anything the file asks of them, so it should not be the first thing a large `paths` list costs

## Status

**done** `render.mjs` (`renderArea`).
Roster lines still wait on whatever room is left after the kinds line and the directives, since what a file imports is a second reading and not a first one; A33 later took the line off the budget entirely, because leaving it to compete meant it gave way in exactly the directories holding the most directives (A6, A33, H10)
