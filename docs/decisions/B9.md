# B9

Section: B. Engine

## Decision

The semantic tier reads repository-authored `tsconfig.json`, so the "libraries read no repository configuration" claim is false. Confine `extends`, force the root file list to the corpus, resolve our own deps from the plugin root

## Why

The v3 claim was untagged and its own evidence section falsified it
