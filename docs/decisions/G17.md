# G17

Section: G. Scope

## Decision

No document quotes code, prompt text or byte offsets read out of a proprietary build, Claude Code's included: a note describes what the build does, and quotes only first-party documentation, open-source source and the output a command prints. `check:docs` refuses a byte offset into a build

## Why

Claude Code ships under a license that reserves every right, and both sets of terms it is used under restrict reverse engineering (`docs/research/what-a-public-launch-rests-on.md`); this repository is MIT and cannot license what it does not own.
Fourteen research notes and the plugin contract quoted minified functions, schemas, built-in prompts and offsets out of the Claude Code and Cursor builds and the Copilot bundle, and every conclusion survived being described instead of quoted.
Each quote sat beside an offset, written as the word and a byte count, grouped in threes or not, or as a bundle name, an at sign and the count, so the offset is the shape a gate can read; a quote with no offset is the review's to catch.
The A/B harness's tests still read the installed build for the model and effort it pins and for engine-shaped variable names, on the developer's own machine, and skip where no build is installed; they write nothing of it anywhere
