# C24

Section: C. The counted-claim model

## Decision

An omission site is reported only where the map stated the claim, on both of the site types C23 introduced

## Why

H16's new site type exists to say "you should have written X", which is a directive.
On a row the map holds at `20 of 31 sites, no convention` the check was nudging an agent to mix `ActiveModel::Dirty` into a plain PORO on the strength of a 20-of-31 ratio, and the map's whole contract is that a count failing the gate prints as a count and never as a directive.
The NIT tier softens it, not the direction.
A body that includes the wrong module is still counted where the map said nothing: "you wrote a different module from the one this area writes" is the count speaking, and "add this module" is the directive the gates refused
