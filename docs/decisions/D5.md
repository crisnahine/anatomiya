Section: D. Gates

## Decision

Authors from `git log -M --no-merges --name-status`, one pass where no history store holds the commits (D15), root commits diffed whatever `log.showRoot` says, unioning rename chains, `-M100%` on a partial clone (F14). Never `git blame`

## Why

Measured: 271x faster (0.84s vs 103s), agrees 99.6-100%, and one formatter commit collapses per-site blame to a single author
