# C2

Section: C. The counted-claim model

## Decision

A dimension with no writable applicability predicate does not ship

## Why

8 of 8 were writable; 3 of them under-count applicability, which is the dangerous direction.
Re-measured over expressjs/express, sidekiq/sidekiq, vuejs/core and mastodon/mastodon, across the 37 of 40 rows that produced a slot in any of them, since which rows those are depends on which repositories are asked: 6 precise rows sit under a 0.25 median applicability share and each names a construct that is simply rare, so the share ranks rows to open and decides nothing.
The under-count the row is about was found by the witness rather than by the share, and by widening it: `service_result_shape` refused every receiver, so `def self.call`, the commonest Ruby service entry form, was not a site at all and the ratio was stated over whichever subset writes instance entry points.
One witness per sentence would not have caught it either, and neither would a sixfold narrowing of `optional_chaining`, the row this contract already names as the measured false-convention case.
A sentence naming a set is only as true as the members somebody wrote down

## Status

**done** `dimensions.mjs` (`assertApplicability`), `pairing.mjs`, `dimensions-ruby.mjs`, `test/applicability.test.mjs`, `scripts/audit-applicability.mjs`.
Writable was already true.
What nothing held was that the predicate a row ships agrees with the sentence anybody would write for it: `applicability` is whatever `run` emitted, so a predicate seeing a tenth of its own construct gives 1.0 over four files and reads as a strong convention.
Each row states the files it can speak about and, where it is partial, what it cannot see, tied to `precision` so the marker and the reason cannot disagree.
The witness is per form rather than per row: every shape the code treats differently gets a source, because one source proves the sentence names something and nothing more.
A closed table of names is one shape, so it is covered from the other side, each member driven through the predicate against a list written out in the test: dropping `next-intl` from the module list changes no shape and makes every file in such a repository inapplicable, and reading the expectation off the table would agree with it by construction
