## Decision

Two sentences under the roster and no others: match sibling test shape, and match directory granularity. The first prints when the tests line printed, the second when at least one root printed a helper facet, and neither carries a number of its own

## Why

These two because they are the two findings the review this design started from actually made: an agent added a vitest file under `__tests__` where the repository writes Cypress, and extracted a one-function module beside a component whose siblings inline theirs.
Both are about which kind of file to create and where, which is the class of finding no shipped row counts, and each has a counted ground directly above it: the tests line is the denominator that said 4 vitest against 102 Cypress on the repository the review was on, and the helper facet is the sibling-module and inline-helper pair.
A sentence with no such ground is a rule this tool did not measure, which is what keeps the list at two.
They read as sentences rather than as claims because the numbers are already on the lines above, so repeating one here would state a count twice and let the two drift
