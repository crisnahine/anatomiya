# C12

Section: C. The counted-claim model

## Decision

An ambient declaration is not module state, and neither is a binding inside a namespace

## Why

`declare const x: number` binds nothing at run time; it describes something declared elsewhere.
It was counted as a module-level const, and `var` inside `declare module 'x'` was counted as module-level too, though it is scoped to the block.
Both moved the ratio on a claim about mutable module state
