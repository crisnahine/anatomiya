# A8

Section: A. Delivery

## Decision

Print one line after a scan and a pin saying what reaches a running session: the new overview on its next prompt or tool call (A92), and the whole map on a new session, a compaction or /clear

## Why

Measured, same cause as A6.
A17 found the one path that picks the new map up without a restart, and it does not change the line: a compaction re-reads every instruction file from disk, so a session that compacts after a re-scan is holding the new counts.
Nothing can make a session compact, and telling a reader to wait for one is telling them to wait

## Status

**done** `summary.mjs` (`RUNNING_SESSION`, printed by both `scanLines` and `pinLines`), `plugins/anatomiya/commands/scan.md`, `plugins/anatomiya/commands/pin.md`.
The restart advice predated A92's changed-map re-delivery and was dropped.
