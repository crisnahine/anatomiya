# A32

Section: A. Delivery

## Decision

CodeQL scans what ships: `test/**` is outside the scan

## Why

Two alerts on the plugin's reader traced a temporary-directory path into `readIfFile`, and the path came from the suite's own `mkdtempSync` fixtures, which is the safe way to make one, handed to the code under test.
Moving the plugin's state out of the temporary directory left that flow sourced by tests alone.
Excluding tests removes the class from the scan rather than dismissing each alert as it recurs, at the cost of the one test-side finding the scan had made, an unescaped backslash in a regex a test built, which is a class the shipped code is still scanned for.
Tests are not shipped and this scan is for what is
