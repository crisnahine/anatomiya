# B78

Section: B. Engine

## Decision

The OpenSSF Scorecard checks are met where code can meet them: the overview's bound and a URL path's words are fuzzed with fast-check, and the checker smoke installs with `npm ci` from a repository whose tag pins its packages by hash. The checks that code cannot meet are dismissed with their reason

## Why

The scorecard workflow uploads each check scoring under 10 as a code-scanning alert, and twelve were open.
Fuzzing scored 0: Scorecard v5.5.0, which scorecard-action v2.4.4 runs, counts a JavaScript repository as fuzzed by a fast-check import in a `*.js` or `*.jsx` file (`checks/raw/fuzzing.go`), and every test here is `.mjs`.
The property tests are worth having whatever the score: the overview's bound broke twice in the work A120 records, once at 41 lines and once by dropping "What lives where", each time on a mix of optional lines the hand-written sweep did not yet hold, and the fuzzed bound fails when the unread-engine lines are printed one per line again.
Pinned-Dependencies scored 9 on one `npm install` in `ci.yml`, the checker smoke's, which installed whatever got v14.4.7's ranges resolved to that day, because that repository ships no lockfile.
Committing a lockfile for it was measured and refused: GitHub's dependency graph reads a lockfile in any directory, and that one carries 37 advisories, 2 of them critical, through got's own dev dependencies.
class-validator v0.15.1 ships a lockfile, so `npm ci` installs what its tag pins and this repository holds no copy; on it the checker tier ran `ok` at a typed resolution rate of 0.99, against got's 0.97.
Binary-Artifacts flags the seven vendored grammars, which are binary by design and held to their packages by hash (B61).
Code-Review needs approvals from a second person, and a full CII-Best-Practices score needs the gold badge, which asks for at least two unassociated significant contributors and a bus factor of two: neither is reachable for a solo project.
Maintained flags a repository younger than 90 days, which this one stops being on 2026-11-11
