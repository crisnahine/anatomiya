# A15

Section: A. Delivery

## Decision

A stated side the model already writes unprompted renders as a counts line, never as a directive; the check enforces it unchanged

## Why

Measured elsewhere: context files pay only for non-standard practices (arXiv:2602.11988), and this tool's own A/B (G5) found no effect on a claim the model writes anyway.
The check keeps full severity because compliance decays within a session (about 5.6% lower odds per generated function, arXiv:2605.10039), so a default is still worth catching once the model drifts off it.
Which side a model writes is a committed table, `plugins/anatomiya/lib/model-defaults.json`, with provenance per entry; `none` and an absent key fail open, so an unmeasured row keeps stating.
A class is read whatever the provenance method says, so `none` failing open holds for the side only: `interface_prefix` and `type_alias_prefix` are seeds carrying a hand-set class `none` (H11), and `test/model-defaults.test.mjs` holds the unmeasured classes to those two.
The table is written by `scripts/measure-defaults.mjs`, which parses the model's own output through the scan's predicates, so the table's number and the map's number are one number.
A side or class is declared the default at 0.8 of at least 20 sites, the same shape as the ratio gate's evidence floor: below either bound the honest answer is `none`, which fails open.
Batches of one model accumulate rather than replace, because 19 sites and 10 sites are 29.
The trials run through the same headless CLI the A/B uses, deliberately: the maps are read by agents inside that harness, so the default that decides a line's worth is the agent as deployed, harness prompt included, not the raw model.
That is how doc_comment_style measured counter (1 of 40 exports commented) where the literature predicted comment-heavy, and the measurement wins.
The six prompts also name the files the model must create, so the filename tally measures the prompt author; the file_naming_case class stays unmeasured until the tasks stop naming files.
A learned row holds one class per key across languages, so a future batch dominated by one language could declare that language's class; split the tasks per language before believing a class the table did not hold before.
A table change ships as a plugin version, so it moves nothing until a human re-scans, and that re-scan can flip stated lines to counts and un-name areas at once: a larger rendered diff than a registry addition produces.
Six shared scenario prompts feed every dimension at once; a construct they never elicit stays under the 20-site floor and reads none, which fails open
