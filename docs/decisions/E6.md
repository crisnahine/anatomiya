# E6

Section: E. Baseline and drift

## Decision

Drift is files changed in mapped areas from the commit the pin and the base ref share, to the base ref, and whose bytes there differ from the pin's, never `..HEAD`

## Why

Over HEAD the branch's own changes count as drift, so severity falls as the change under review grows.
The range between two commits is symmetric, which leaves the same hole from the other end: `anatomiya pin` puts the pin at HEAD, so pinning on a branch read the branch's own commits as a map that had moved.
Measured on a 12-file repository whose branch touched 6 mapped files: pin, scan, check reported "severity capped at FIX: 6 of 12 mapped files changed since the pin" against a pin that was HEAD, so a branch silenced its own findings by being large.
Drift is the base's own progress past what the pin already holds, and where the pin is a descendant of the base that is nothing.
Running from the shared commit alone opens the mirror of the same hole: after a squash merge the shared commit sits behind work the pin already holds, and a base whose tree is byte-identical to the pin reported 40 of 130 mapped files and capped again.
A path is drift when the base moved it since the shared commit and its bytes there differ from the pin's, which is both ranges at once.
One case is left standing and is worth naming: in a shallow clone `git merge-base` exits 1, the range falls back to the symmetric one, and a branch's own commits read as drift.
Reporting no drift there is worse, because an unmeasurable drift caps every finding at FIX permanently

## Status

**done** `git.mjs` (`resolveBaseRef`, the one resolver both phases read), `baseline.mjs` (`mergeBase` before the range).
The check hands the resolver the base commit it resolved rather than the ref's name: a shallow clone's fetched base has no ref, and re-resolving the name capped every finding under "cannot resolve origin/main".
The commit handed over is the fork point where there is one, named explicitly, since the report's `base.sha` is the base ref's own tip
