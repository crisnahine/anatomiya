# H17

Section: H. Layout

## Decision

`extOf`, `stemOf` and `withoutExtension` read one shared split, and that split recognises `.d.ts`, `.d.mts` and `.d.cts` as their own extension rather than the last dot alone

## Why

Measured: cal.diy's `packages/types` reported `30 .ts` where 29 are `.d.ts`; appsmith's 3,661 is 3,640 plus 21; prisma at 26 of 199 areas, one saying `24 .ts` where 16 are declarations.
The old stem left a stray `.d` on every declaration file too, so `image.d.ts` read `image.d`.
The three answers share one `splitBase` because this module's own header says a rule matching on the basename and a rule matching on the directory have to agree where one ends, and one copy drifting is a file counted twice: `withoutExtension` was left counting dots and on `index.d.ts` returned `index.d`, which no longer ends in `/index`, so `siblings.mjs` stopped resolving a package whose entry is a declaration file through its own directory

**done** `paths.mjs` (`splitBase`, `extOf`, `stemOf`, `withoutExtension`), pinned by `test/paths.test.mjs`, which asserts all three agree on the same paths
