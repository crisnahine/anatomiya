# H51

Section: H. Layout

## Decision

A Rust file that holds its own tests is asked for no namesake test and is counted in a clause of its own, `34 hold their own tests`, on the root line, the tests line and an area's kinds line. It is never a test file

## Why

It is precedent to the `test_precedent` gate, and to H38's finding where a test of another language is judged against its directory: no `.rs` path is a test by its name, so the finding is asked of none: a crate's first `tests/first.rs`, beside a crate with five such files, gets no notice and no finding. cargo collects a file directly under a crate's `tests`.
A `#[test]` in a file with a `tests` directory anywhere above it, or in one named `tests.rs`, makes that file a test file (H49).
In every other file `#[test]` is the file testing itself, in a `mod tests` or beside the code.
A namesake test is another file carrying the source's stem, and a module inside the file is not one.
Counted as having a namesake: ripgrep `34 of 90 .rs files under crates`, tokio `49 of 344`, serde `1 of 20`, where no file of ripgrep's or serde's has a test file of its stem and 2 of tokio's 49 do; the words name a file a reader then looks for.
Counted as owing one: `0 of 90`, `2 of 344`, `0 of 20`, a false zero over 34, 47 and 1 files that carry their tests.
Counted apart: ripgrep `0 of 56 have a namesake test; 34 hold their own tests`, tokio `2 of 297` and `47 hold their own tests`, serde `0 of 19` and `1 holds its own tests`.
Given up: the denominator is no number the extension clause prints, and a file that holds its own tests is not credited with a test file of its stem either, which 2 files in ripgrep and 10 in tokio share a stem with; and a file whose `#[test]` functions are all written inside `macro_rules!` is not read as holding its own tests, code inside a macro being outside the tree, so three ripgrep files (`crates/globset/src/glob.rs`, `crates/globset/src/pathutil.rs`, `crates/matcher/src/interpolate.rs`) sit in the 56 and outside the 34.
As a test file it would put every such source file on the tests line, 34 beside the 15 cargo collects
