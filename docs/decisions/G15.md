# G15

Section: G. Scope

## Decision

`DECISIONS.md` is an index, one line per row, and each row's Why and Status live in `docs/decisions/<id>.md`; `check:docs` holds the two to each other and reads the row files for every rule that reads a row

## Why

A search of the one-table file answered with whole rows, 17,194 bytes at the longest, and such searches returned 9.84 MB over 76 sessions.
Split at 319 rows, the index is 80,837 bytes against 709,540, and `grep -n "A92" DECISIONS.md` returns 930 bytes against 19,153.
The Why and the Status are written one sentence per line, so a search of the directory answers with a sentence: the longest line in a row file was 1,744 bytes.
The split was proved before anything was written: the index and the 319 files rebuilt the old file byte for byte, the 9 rows holding `\|` and the 5 rows with no Why included.
Left unread after the split, the row files would have passed every rule that read a row: the gate as it stood passed on the converted tree.
A short status read as the text before the first colon answered `see https` for a Status opening with a URL, so it is one of three words and anything else is a fault
