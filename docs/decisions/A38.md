# A38

Section: A. Delivery

## Decision

The shipped set is stated in `package.json` `files` and read back through `npm pack --dry-run --json --offline`, against every file the hooks and the command files reach

## Why

The plugin root was the repository root when this was written, so nothing about the tree said which files belong to the plugin and which are how the plugin is built.
A40 moved it, and the rule outlived its premise: a plugin ships its directory whole, so `files` is still the one thing that says which of those files are its own, and the plugin beside it that has no list at all is checked by the walk instead.
`files` was the one list that said, and nothing read it: the package is private, so no pack or publish ever happened, and it was wrong in both directions in silence.
It omitted `hooks/`, which is the declaration the loader reads before anything else, and its `.claude-plugin/` entry shipped `marketplace.json` along with the manifest, which describes the marketplace and not the plugin. npm answers what the list covers rather than this re-implementing it, because the semantics are not plain globs: a directory entry is recursive, a negation subtracts, a nested `.npmignore` subtracts and is itself not shipped, a few names are added whatever the list says, and an entry naming a path that does not exist is passed over without a word, which is the one that made the gate worth having.
The other half is walked rather than listed, from every starting point the loader has: the hook declaration, the mcp file, and every file under the commands, agents and skills directories, each read where the manifest puts it rather than only where the convention does.
A first pass read two of the five, and widening it to all five carried an exemption with it that had been written for the two files with a check of their own, so for one round no command, skill, agent or mcp file was checked for being shipped at all.
From each starting point it follows relative specifiers through `from`, a bare `import` and any call, since this repository loads its one JSON table through `createRequire(import.meta.url)("./model-defaults.json")`, where the callee is a value and no pattern can look for a name.
A hook declaration is parsed as JSON before its command is read, because the quotes around the path arrive escaped and a pattern over the raw bytes took the backslash before the closing quote as part of the filename
