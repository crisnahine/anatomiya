# A99

Section: A. Delivery

## Decision

The refresh and the end-of-turn check, whose payloads name no file, take the checkouts directly below the session's directory that hold a map of their own when the walk up finds none; more than eight side by side take none

## Why

A session started in the directory holding sibling checkouts (the layout a project split into repositories is opened from) got {} from both: SessionStart, FileChanged and Stop name no path, so H40's tool-call path does not apply, and `ownLayout` only walks up.
No worker started, no HEAD was watched, and a turn that added a function in a child was never asked about.
One level only, a checkout root with a .git and its own facts.json, since a .claude copied without a .git opts nothing in (A24) and a borrowed worktree map is not refreshed (A93).
Eight is the line between one project split in a few and a shelf of projects: past it the session has named none of them, and a worker each at every session start is nobody's request, so it answers as before; none rather than the first eight, so the answer does not hang on alphabetical order.
The reuse check names files from the session's directory (api/src/x.ts) while each mark stays over the checkout and the path inside it, so a session that moves into the checkout is not asked again and a copy at the same path in a sibling checkout is.
The hold notice names each held checkout and says to pin it from a session inside it, since `/anatomiya:pin` run above the checkouts finds no repository.
The echo is unchanged: its calls name the file.
A cd cannot move the watch, since CwdChanged reaches only settings hooks
