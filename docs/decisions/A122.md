# A122

Section: A. Delivery

## Decision

The end-of-turn reuse check (A91) reads view templates as well as source: ERB (`.erb`), Razor (`.cshtml`, `.razor`), HAML (`.haml`), Slim (`.slim`), Jinja (`.jinja`, `.jinja2`, `.j2`) and Go templates (`.tmpl`, `.gotmpl`), and the markup of a Vue or Svelte component. A hunk asks where a line holds template code, and one that adds markup alone asks nothing

## Why

A view is where a helper's logic is copied most often, and no scan reads one, so a turn that wrote `<% if URI(link).host != request.host %>` into a Rails view was never asked about, where the same comparison in a helper was asked and found `is_external?` in 20 of 20 whitehall sessions.
ERB's code is the text between `<%` and `%>`; `<%#` opens a comment and `<%%` is a literal `<%`, both as Ruby's ERB reads them.
Razor's code follows an `@` that stands after a character that cannot end a word, so an e-mail address is text and `@@` a literal `@`, and a block opened by `@{`, `@code {` or `@functions {` is code through the brace that closes it; `@*` opens a comment.
A directive that names a type, a namespace or a route, `@model`, `@using`, `@page` and the like, runs nothing and asks nothing; a statement whose body is a block, `@if`, `@foreach`, `@switch` and the rest, holds C# on every line of it that is no markup, through the brace that closes it and an `else` after it, and a brace inside a C# string opens and closes nothing.
HAML and Slim ask on a line of Ruby (`-`), an output line (`=`), a tag whose content or attribute is Ruby, and an interpolation (`#{}`); a comment asks nothing.
A Jinja expression or statement and a Go template action ask where they compute: a call, a filter, an operator; a name read as it is, `{{ user.name }}` or `{{ .Name }}`, asks nothing.
A component's markup asks only where an expression computes with a literal, arithmetic on a number, a method called with a number (`toFixed(2)`) or a string built with `+`, since a binding, a call with names alone, a comparison and `n++` are written on most lines of a template, and the component's own logic is in its script, which is read whole.
An `.html` file is not read: it is Angular's, Vue's, Django's or plain markup, and no one rule reads all of them.
A template is refused by the corpus's own path rules (a denied path, an excluded directory) and keeps neither of its file checks: no generated marker or link check reads it
