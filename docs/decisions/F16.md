# F16

Section: F. Safety

## Decision

No module in `lib/` imports its way back to itself

## Why

A cycle loads under ESM hoisting, so nothing fails at run time and the first symptom is a module reading a half-initialised binding from a partner still evaluating.
`ruby.mjs` carried a comment refusing an import for exactly this reason and the comment was deleted in the same change that took the import, closing `ruby.mjs -> dimensions.mjs -> dimensions-ruby.mjs -> ruby.mjs`.
The Ruby AST helpers living in the parser bridge are what make the registry unreachable from it, so shared code both bridges need goes in a module that imports nothing of ours
