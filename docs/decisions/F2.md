Section: F. Safety

## Decision

Lexical containment, then realpath both sides, fail closed, read the resolved path

## Why

v3 dropped this to one sentence about symlinked directories, which exempts symlinked files

## Status

**done** `corpus.mjs` (the read), `rules.mjs` (`resolveInside`), `write.mjs`, `facts.mjs`, `check.mjs` (the write), `baseline.mjs` (`pinFile`, `pinTarget`: the pin, read and written).
It held for the corpus and for nothing else, which is the half that only reads.
Measured: a tracked `.claude -> ../victim`, git mode 120000 so it survives a clone, had the scan write the map and `facts.json` into a directory the repository does not own, name that directory's files in the always-loaded overview, and remove one of its `anatomiya-*.md` files on the next scan.
`join` normalises `..` and resolves no link, so lexical containment is not containment.
Every component is resolved now, a dangling link is refused rather than created through, and the two directories are checked before anything is written, since one link at `.claude` escapes with both.
The planning half also refuses a directory that a regular file holds, or that sits under one (`.claude`, `.claude/rules`, `.claude/anatomiya`), and names the path in the way.
Before this, a dry run answered 'would write 2 files' and the real scan died on a raw `EEXIST` or `ENOTDIR` out of `mkdir` (`write.mjs` `resolveDirs`)..
The scan fails closed; the check reports, because refusing a branch over a link is the blocking behaviour this design rejects.
The pin was left joined, so `pin` wrote baseline.json through the same link and every later scan read its population from there; it resolves the same way now, refuses in the planning half so a dry run refuses too, and reads a pin outside the repository as no pin.
Inside the repository was then found not to be the rule: committed `.claude/anatomiya -> ../.git/hooks` and `.claude/rules -> ../src` both resolve inside it, and `pin` and `scan` wrote into `.git/hooks` and `src` while printing `.claude/...`.
`resolveInside` holds any path under `.claude` to the repository's own `.claude` now, which must itself be a real directory and not a link, so a link out of it is refused by every reader and writer of the two directories (`outsideClaude` spells the refusal).
Except `.claude/rules`, which may lead anywhere in the working tree outside its git directory.
Measured by the corpus: calcom/cal.diy commits `.claude/rules -> ../agents/rules` to share one rules directory between agents, Claude Code reads it through that link, and held to `.claude` the scan refused the whole repository where 0.10.2 wrote its map.
Git matches no pathspec and no ignore pattern past a symlink, so a map written through that link is tracked, ignored and changed only under the link's target.
The refresh's tracked-map guard (`refresh.mjs` `mapTracked`) and the pin's clean-tree test (`commands.mjs` `refuseUnlikeHead`) read it there through `rules.mjs` `trackedRulesDir`.
Spelled as `.claude/rules/...`, a map committed through the link read as untracked and every move of HEAD rewrote it, and a map a scan had rewritten there refused the pin.
Where core.ignorecase is set both pathspecs carry `icase` (`git.mjs` `caseMagic`): git matches a pathspec case-sensitively against the index spelling, so a directory renamed in case outside git hid the committed map under either spelling.
The README's first exclude line names the link's target for the same reason.
What lands there is only this tool's own `anatomiya-*.md`, removed only by its own frontmatter.
The leaves are read the same way: `readFacts` and `readPin` resolve `facts.json` and `baseline.json` themselves, where a link out of the repository had been followed and its areas or its pin returned; a write replaces such a link as an entry.
A refusal names the path the repository spells rather than where it resolves (`blockedOnTheWay`): `.claude/rules -> ../README.md` once read "README.md is not a directory ... remove it", which tells an agent to delete the README.
`.cursor/rules` and `.github/instructions` (A102) are held to a stricter rule, with no link allowed at any component (A104)
