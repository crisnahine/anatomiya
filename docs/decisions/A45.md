# A45

Section: A. Delivery

## Decision

A payload `JSON.parse` refuses is read for the members that can still be had: string members, at the top level and inside `tool_input`, whole, and short enough to be a path

## Why

`JSON.parse` reads a document or nothing, so a complete payload followed by one stray byte answers the same as no payload at all, and one larger than the megabyte cap answers nothing whatever the cap keeps.
Both are ordinary rather than hostile: a `Write` of a generated file carries the bulk in `tool_input.content`, a `Read` of a minified bundle carries it back in `tool_response`, and the four short fields the hooks read are sitting in the first hundred bytes of both.
Measured on 0.4.2: a 240-byte envelope with 2 MB of padding after it, and a 1.43 MB single object, each cost the turn its map; the branch keeping the first megabyte could only ever answer for padding that was whitespace, which is the one kind `JSON.parse` skips

## Status

**done** `payload.mjs` (`asPayload`, and the block written twice: `NESTED_MEMBER`, `isSpace`, `skipSpace`, `fieldsIn`, `readMembers`, `put`, `endOfString`, `decodeString`, `skipValue`), The grammar is read rather than matched, because the cargo being stepped over is a file's own text: a reader that found `"cwd"` inside one would answer another repository's path for a live write, and nothing here looks inside a string.
Every value answered is decoded by `JSON.parse` on that value's own token, so escapes, surrogate pairs and a Windows path full of backslashes stay the parser's business rather than becoming a second implementation of it.
A value longer than `PATH_MOST` names no place a filesystem can hold, so it is the payload's cargo and is stepped over as a span rather than copied.
Depth is counted rather than recursed: a value nested fifty thousand deep is a stack overflow in a reader that calls itself, and this runs before every tool call.
A second reader of the same shape would have to hold the same answers, since neither may run a file outside its own root, and the cases that drive this one are written against a list of payloads, the ordinary ones and every shape that reaches the reader of last resort, and one compares the block itself character for character, from `NESTED_MEMBER` to the end of `skipValue`.
The behavioural one can only catch a drift some payload in its list happens to reach, and three did slip past it while the compared span began lower down: a `\f` added to `isSpace`, a bound moved from 4096 to 64, and `skipSpace` stepping by two.
`VALUE_MOST` stays outside the compared span, since the two spell it differently on purpose, and is held to a number by a pair of payloads either side of it
