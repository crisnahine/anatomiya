# C11

Section: C. The counted-claim model

## Decision

A dimension reads the value inside its type wrappers

## Why

`null as any` is null, and the walkers matched on the node type of the expression they were handed, which is a `TSAsExpression`.
`return null as any` was not counted as a return of null: react writes it 24 times and vscode 20, every one a conforming site nobody counted.
`x ?? ([] as Foo[])` is a default taken with `??` and was not counted as one either, because the right side was not a literal by node type.
`satisfies`, `!` and `<T>x` wrap the same way, and oxc preserves parentheses, so `(null as any)` is two wrappers deep
