# A50

Section: A. Delivery

## Decision

Every export is read somewhere outside its own file, held by a guard in `test/modules.test.mjs` over every `.mjs` under the plugin, `scripts` and `test`

## Why

Twenty-five exported names appeared in no file but their own, and five more the guard found beside them; one of the twenty-five, `assertDeclaredFields`, stayed exported with a test, so twenty-nine went private.
An export nobody reads is interface with no caller, it widens what the module promises, C19 counts it as a site, and nothing kept it honest.
The registry gates stay exported standalone so a failure names the rule under test, and the one of them no test drove has a test now rather than an exception.
`FILES_MOST` was the default of a parameter `shadowsFor` takes, so the bound is pinned by behaviour first: two thousand files are read and the next one stops the sweep.
Read by word rather than by import edge, because tests reach some names through a namespace or a dynamic import, which only makes the guard lenient

## Status

**done** twenty-nine names made private across twenty files, `exportedBy` reads a source with its strings blanked so a fixture's `export` lines are not the file's, and the guard is green over the whole tree.
This repository's own `exported_symbol_case` ratio moves with it, and the map is regenerated rather than committed
