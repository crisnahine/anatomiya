# Two rows asked of the tree-sitter languages

Date: 2026-10-28. Two questions the JavaScript and Ruby rows already ask had never been measured over
the seven languages a tree-sitter grammar reads: which class a class inherits (`extends_base`,
`class_base`), and whether output goes through a logger (`route_logging`, `logger_over_puts`). They
were measured by the bar `2026-10-07-refused-rows.md` uses, on the same 21 repositories, and each
became a row in the languages that cleared it (C69, C70). Section 3 records the five pairs the bar
refused and the owner asked for anyway (C71), read through the rows as they ship.

How it was taken: a throwaway script read each repository in place through the build's own
`collect`, `discover` and `parseTreeFile`, with the shipped rows `class_inherits` and
`logger_over_print`. A ratio is conforming sites over candidate sites, summed over a repository's
areas; for `class_inherits` a site conforms when its base is its area's commonest. Every clone was
`--depth 1` at the default branch's head on 2026-10-28: django `a6304ac10554`, flask `d086db856be1`,
fastapi `79cab5bed28b`, laravel/framework `5c82f4042ec4`, composer `b56a3f558a53`, Slim
`3675bf6baac6`, commons-lang `a5d6c5ed8847`, junit5 `ca61d8b0d9e8`, gson `57731049da3e`, jellyfin
`02c2951eb72d`, serilog `43105b350953`, Newtonsoft.Json `52fa3aef1f2c`, ripgrep `91f5d22ef48b`, tokio
`0d38f8349f4d`, serde `0db9b3b504bc`, okhttp `a11e55f85847`, ktor `d96280165fc9`,
kotlinx.serialization `6f6a2e66c3db`; caddy, gin and hugo for Go's logging question.

The bar: one of a language's three repositories under 0.90, and 0.15 or more between the lowest and
the highest.

`log.SetFlags` among them, as a write through a logger. Section 3 has Go read by the rule that ships,
which counts only a call that writes a line, and there Go clears the bar.

Kotlin's `System.err` and `System.out` and C#'s `Console.Error` and `Console.Out` count as prints, as Java's do;
okhttp, ktor and jellyfin read 17, 2 and 2 more sites for them than a first build. Laravel's count is the shipped row's, which passes over the `echo` and `print` of a file holding
markup outside its tags, a template writing its page; a first build counted 41 sites there.

The row is a capability row, as `logger_over_puts` is: it is offered only where three files already
write through a logger (C14). A repository that only prints, composer and serde here, is never asked.
Several site counts are small (gson 2, flask 3, Slim 4); C51 kept Slim's 7 for the same reason, since
the bar is about whether repositories differ and the gate decides each area on its own.
