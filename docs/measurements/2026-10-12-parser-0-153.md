# What oxc-parser 0.153.0 changes in a map (2026-10-12)

0.15.0 takes `oxc-parser` 0.153.0 and `flow-remove-types` 2.334.0 where 0.14.0 shipped 0.151.0 and
2.333.0. The same build of this version's code, 665c4fb0, was scanned with each pair installed.

## How it was measured

Two copies of 665c4fb0 from `git archive`, one with 0.151.0 and 2.333.0 installed and one with
0.153.0 and 2.334.0. For each of the 60 repositories (the 35 corpus repositories and the 25 of the
seven languages), two copies of the repository were scanned, one by each build, and every file under
`.claude` was compared with the scanned root's path and the per-run times masked. The scan's own
output was compared the same way.

## What it showed

- Every scan exited 0 under both parsers.
- Every overview and area file is byte-identical in all 60 repositories.
- `facts.json` names the parser's version, `0.153.0` for `0.151.0`, in the 40 repositories whose
  scan parsed JavaScript or TypeScript. In 8 of them, the 8 with dependencies installed for the
  type checker (Ghost, the react-front-end, eslint, mastodon, prisma, react, typeorm and
  webpack), `measuredUnder` moves too: it is a digest of what the checker's verdicts were measured
  under, the build included.
- `refresh.json`'s `stamp` differs in all 60, since it is a hash over the record it stamps.
- The scan's output differs only in its `engines:` line, `oxc 0.153.0` for `oxc 0.151.0`, and in the
  time it took.
