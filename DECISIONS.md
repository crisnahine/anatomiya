# anatomiya build contract

Every row is a finding that survived review or a probe that overturned an assumption, reduced to the
decision it forces on the code. This replaces the v1/v2/v3 specs as the thing to build against; those
are history. Status is what the code does **today**, not what it should do.

Sources: five-lens verification of v3 (26 blocking findings), six empirical probes, a ten-repo
public measurement, a 4,616-comment classification, and a 237-entry glossary re-audit.

## What is deliberately not built

- **No hook as the delivery channel.** Worst-trusted, highest complexity, measured being flagged as
  prompt injection, and measured at 10 to 40% adherence against 100% for the always-loaded file. A24
  adds a hook *beside* that channel rather than instead of it, which is a different question: the
  100% channel keeps carrying the map and the hook adds recency and a timestamp on top. If the hook
  were ever the only delivery, this refusal stands.
- **No MCP server.** Nothing to expose.
- **No skill.** It would spend resident context describing the tool instead of the repository. The
  five commands are the plugin's only entries in the listing, one line each.
- **No health score or grade.** It changes nothing about the next line of code.
- **No import-direction (layering) dimension.** Probed on four repositories (2026-08-16): a
  require() repository is invisible to an import-statement site, the cross-area graph is sparse
  everywhere but vscode, and at this tool's own Wilson gate 0 of 4 repositories put even a third
  of their pairs over the bar. `docs/measurements/2026-08-16-layering-probe.md` has the numbers
  and the revisit conditions.
- **No restating what the linter already enforces.**
- **No row for the unread classes that were measured and refused.** Each but locale key parity was
  measured against the bar over the three corpora on 2026-10-23, and where the numbers cleared it,
  put to sessions with no map: in every session that wrote the construct the agent matched the
  repository's side, in all but two after globbing or reading the siblings first. The URL forms C59
  leaves out (React Router 7 config, TanStack file routes, `path` arrays, Ember's route map, file
  routers, links) are C63; the YAML extension, Markdown and data file names, CSS classes and locale
  key parity are C64, and have no area to stand in; a directory's name, a test's title, a module
  constant's and an object key's case, i18n key case and shape, Rails views' lazy keys, the TODO
  form and a message's final period are C65; an i18n key's presence in the base locale,
  data-definition files, a workflow's extension and an action pinned to a sha are C66, where a
  migration that ships with its schema edit is already a co-change claim. The tables and the session
  trials are in `docs/measurements/2026-10-23-unread-classes.md`, and each class has a dropped row
  in `docs/dimension-intake.md`. The URL rows speak JavaScript and Ruby (C59) and Python, Java, C#
  and Rust (C62); PHP, Go and Kotlin were measured and are not asked, for the reasons C62 gives.
- **No "catches bugs earlier" claim.** Measured: 1 of 317 defect comments across ten repositories was preventable by a conventions map. Nine of ten repositories scored zero.
